## 1. 공통 템플릿 (모든 프롬프트 재사용)

**공통 positive 접미사** — 모든 프롬프트 끝에 이미 포함. 새 컨셉을 만들 때도 끝에 붙일 것:
```
vertical 9:16, no text, no watermark, no logo, no subtitles
```

**베이스 negative** — 각 클립은 이 6종 앞에 **자기 고유 실패모드 3개를 먼저** 배치한다(평가단 C7: 맞춤 방어가 베이스에 묻히지 않게):
```
blurry, distorted, low quality, text, watermark, logo, captions, warped faces, extra limbs, flickering, warping fingers, oversaturated colors, low resolution, jittery motion
```

**반전형 연속성 키워드**(클립2에 필수 — 모핑·플리커 방지):
```
maintain scale, preserve shape, keep colors consistent, gradually change the environment, seamless continuation from the reference frame
```

**5파트 황금공식**(모든 positive가 이 순서): `카메라 무빙(+엔드포인트)` · `장면 셋업/주체` · `주체 동작(begin→middle→end)` · `라이팅(구체어)` · `시간/무드`. **한 클립 = 한 의도**(zoom in AND pull back 같은 모순 지시 금지).

> **Veo 네거티브 처리**: Veo는 네거티브 칸이 없으므로 프롬프트 끝에 `avoid: ...` 절로 붙인다(05§1-2). Kling/Seedance는 별도 negative 칸 사용. 각 항목에 둘 다 제공.

> **루프 주의(평가단 Nice-to-have 5)**: "완성→역재생으로 카오스 회귀"는 **AI가 단일 생성으로 못 만든다**. 프롬프트의 `seamless loop ...`는 의도 표기일 뿐, 실제 되감기 루프는 **CapCut에서 클립을 reverse해 붙이는 후처리**(05§3-2 방법 B)로 만든다.

## 2. 포맷 공식 + 모델 매핑 요약 (03/04 근거)

**공통 타임라인** (전 클립 9:16 세로):
```
[0초=썸네일] 최강 비주얼·패턴 인터럽트 (정지/평범 인트로 금지)
[0~2초]      비주얼만으로 "이게 뭐지?" 후킹 (2초 후킹 = 유지 +19%, 검증 필요)
[3초]        유지 분기점 (3초 유지율이 바이럴의 85% 결정)
[중반]       단일·매끄러운 동작 (따르기/자르기/슬로 푸시인)
[마지막 1~2초] 페이오프 (반전 / 스케일 전환 / 완결 클라이맥스)
[루프]       끝→시작 seamless (재시청·완주 공학)
```

**모델 매핑** (★ 생성 직전 `models_explore`로 실제 라벨 재확인 — 검증 필요):

| 카테고리 | 1순위 모델 | 길이(생성) | 이유 |
|---|---|---|---|
| AI ASMR (글래스 컷·텍스처) | **Kling 3.0** | 5초→편집루프 | 액체·결로·매크로·가성비 |

| 반전 시네마틱 (2클립) | **Veo 3.1** | 5초×2 | 포토리얼 천장 = 반전 사실감 |
| 미니어처 / Tiny World | **Kling 3.0** (틸트시프트 키워드) | 5초 | "miniature/tilt-shift/scale" 필수 |

**왜 거의 5초 생성인가**: 짧을수록 완주율 유리(2026 완주 바 ~70%, 검증 필요). 메인 발행 길이(ASMR 8~15초 / 무드·스케일 10~20초)는 **편집 후 최종 길이** — 5초를 루프·변주로 늘려 채운다(05§3-2).

**반전형 2클립 기법**: ① 클립1(평온/셋업 5초) 생성 → ② 마지막 프레임 이미지 추출 → ③ 클립2의 start reference(첫 프레임)로 업로드(Seedance 2.0 또는 Kling first-frame) → ④ 연속성 키워드 첨부 → ⑤ CapCut 스티칭(겹치는 1프레임 트림) → ⑥ **컬러그레이드는 합친 뒤 한 번에**. 쌍 스티칭 ~80% vs 단일 10초 ~55% 성공률.
