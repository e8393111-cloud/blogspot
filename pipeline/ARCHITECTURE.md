# 블로그스팟 자동화 파이프라인 아키텍처

## 파이프라인 개요

두 개의 독립 라인으로 운영됩니다.

### SEO 라인 (기존)
```
01_원본키워드 → 02_점수판 → 03_검색분석 → 04_채널각도 → 05_제목생성 → 06_발행패키지
```

### 뉴스 급행 라인 (신규)
```
구글트렌드/브랜드키워드
  → 03A_실시간뉴스감지기 (네이버뉴스API)
  → 03B_뉴스팩트정리기 (OpenAI)
  → 05N_뉴스형제목생성
  → 06N_뉴스형발행패키지
  → 5_hub_queue
```

## 기존 시트 확장 필드

### 2_점수판 (추가 컬럼)
| 필드 | 설명 |
|------|------|
| news_count | 최근 뉴스 기사 수 |
| is_breaking | YES/NO - 장애/사고형 키워드 여부 |
| content_route | SEO / NEWS_FAST |
| news_checked_at | 뉴스 확인 시각 |

### 4_채널각도 (추가 컬럼)
| 필드 | 설명 |
|------|------|
| source_urls | 출처 기사 URL 목록 |
| fact_summary | 사실 요약 JSON |
| content_mode | evergreen / breaking / recovery |

### 5_hub_queue (추가 컬럼)
| 필드 | 설명 |
|------|------|
| publish_mode | auto / semi_auto / manual |
| manual_review | YES/NO |
| event_expires_at | 이슈 만료 시각 (발행 후 24시간) |

## 발행 규칙

| 조건 | 처리 |
|------|------|
| 기사 2개 이상 + 내용 일치 | 초안 자동 생성 |
| 회사 설명 또는 대형 매체 확인 | 자동발행 가능 |
| 출처 엇갈림 | manual_review = YES |

## 뉴스형 본문 구조
1. 지금 무슨 일이 있었는지
2. 언제부터 언제까지였는지
3. 현재 정상화됐는지
4. 이용자에게 어떤 영향이 있었는지
5. 지금 사용자가 확인할 것
6. 업데이트 시각
