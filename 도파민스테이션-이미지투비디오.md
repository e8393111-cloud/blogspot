## 0. Image-to-Video 2단계 워크플로우

**① 이미지 생성 (1단계)**
- `[A] 이미지 프롬프트`를 **text-to-image** 모델에 넣어 **레퍼런스 스틸 1장**을 뽑는다.
- 이미지는 **퀄리티·구도·질감·라이팅·색을 고정**하는 단계. 카메라 무빙·시간변화는 표현하지 않는다.
- 권장: text-to-image (Seedream / Flux / Nano-Banana 계열 등 고해상도 이미지 모델). 9:16로 생성.

**② Image-to-Video (2단계)**
- 1단계 스틸을 **레퍼런스(first-frame)로 투입**하고 `[B] 비디오(모션) 프롬프트`를 적용해 움직인다.
- 비디오는 **카메라 안무 + 시차 4단 + 단일 히어로 마이크로 모션 1회**만 담당. **새 사물·새 형태를 추가하지 않는다.**
- 권장 비디오 모델: **Seedance 2.0** / **Kling first-frame** / **higgsfield Video 3.0** (5s · 9:16).

**왜 페어로 나누나 (AI 약점 회피)**
- 이미지가 "퀄·구도 고정" → AI가 강한 정지 질감(굴절·서브서피스·bokeh)을 깨끗하게 확보.
- 비디오는 "카메라 + 1회 모션"만 → 정밀 물리(손·칼·군중·화염·낙하) 시뮬을 시키지 않아 어색함 원천 차단.

## 3. 체크리스트

**[A] 이미지 프롬프트 — 반드시**
- [ ] 카메라 무빙·시간변화(orbital/push-in/pulse/bloom 등) **금지** — 정지 스틸만.
- [ ] 히어로 1개 + 발광·반투명·굴절 질감 + 구체 라이팅·색 + 배경 bokeh **포함**.
- [ ] 접미사 `cinematic, hyper-detailed, volumetric light, internal refraction, vertical 9:16, no text, no watermark`.
- [ ] 반전형은 **변환 전 상태**로만 묘사(나비·숲을 이미지에 그리지 않음).

**[B] 비디오 모션 프롬프트 — 반드시**
- [ ] **새 사물·새 형태 등장 금지**(반전형의 reveal 제외 — 그건 모션에 1회 명시).
- [ ] 카메라 안무(orbital+하강+push-in) + 시차 4단(far/mid/near/closest) + 히어로 모션 **1회만**.
- [ ] 모션은 `one single ... once, then settles/stills`로 정지 회귀 → 루프.
