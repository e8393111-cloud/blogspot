## 모드 선택
- EDIT: 사용권과 변경권이 있는 실제 사진을 실제 입력으로 제공해 편집. 파일 설명만으로 대체하지 않는다.
- GENERATE: 새로운 이미지가 필요하면 GPT 이미지로 생성 가능. 실사진 미확보 때도 가능하며, 반드시 RAW로 후퇴할 필요 없다.
- RAW: 사용자가 원본을 요청했거나 변경금지 자료이거나, 편집 불필요/실패 후 원본 사용이 합리적인 경우. 이유 기록.
- OMIT: 적합한 결과를 확보할 수 없는 경우. 필요한 정보는 본문에 보존하고 대응표 갱신.
- 각 이미지 제작 전에 모드, 실제 소스 또는 생성 목적, 보존할 요소, 변경할 요소, 카드 문구·비율·삽입 위치를 명시한다.
