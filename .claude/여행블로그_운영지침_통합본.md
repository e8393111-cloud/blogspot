# 여행블로그 운영지침 — Git 실행본

> 이 문서는 프로젝트 소스의 운영지침을 Git 작업에 맞춰 정리한 실행본이다. 과거 지침의 임시저장 기본값과 메인 Chat 선제작 흐름은 현재 Git의 Work-first 자동화 규칙으로 갱신되었다. 적용 순서는 사용자의 현재 요청 → `.claude/00_여행블로그_MASTER.md` → `.claude/00A_여행블로그_AUTOMATION_FIRST.md` → 이 문서 → `.claude/blog-image-project-instructions-v2.md` → 해당 글 지시서다. 사실관계 충돌은 출처로 확인한다.

## 시작과 대상 선정
1. `AGENTS.md`, `CLAUDE.md`, `.claude/performance/README.md`, MASTER, AUTOMATION_FIRST, `.claude/PUBLISHED-REGISTRY.md`를 읽는다.
2. 기본 저장소는 `e8393111-cloud/blogspot`, 작업 브랜치는 `claude/blog-agents-seniors-bdb75n`이다. 사용자가 지정한 브랜치가 있으면 그 지시가 우선한다.
3. 다음 글을 고르기 전 실제 네이버 공개 목록과 PUBLISHED-REGISTRY를 대조한다. 해당 폴더의 STATUS, area1, area2, photos/CREDITS, 실제 사진을 확인한다. 최근 커밋이나 폴더 날짜만으로 다음 글을 결정하지 않는다.
4. Claude의 `검수미달` 표시는 접수를 막지 않는다. 실제 원고의 오류는 독립적으로 검수·수정한다.

## 한 글 처리
- 사용자의 `다음 글`, `진행`, `발행해줘`는 별도 범위 제한이 없다면 한 글 전체를 끝내는 시작 신호다.
- 브라우저가 정상일 때는 Work 1회 안에서 Git/프로젝트 소스 확인, 원고 검수, 최신 사실·링크 검증, 이미지 준비·자체검수, 네이버 서식·이미지·링크 입력, 최종검수, 발행 상태 기록까지 처리한다.
- 기존 임시저장 글은 새 글로 중복 생성하지 않는다. 사용자에게 이미 확보된 파일을 반복 요청하지 않는다. UI 동작이 2회 실패하면 동일 행동을 반복하지 말고 안전 저장·대체 방식으로 전환한다.
- `임시저장만`, `발행 금지`, `검수 후 승인` 지시가 있으면 그대로 종료한다. 그렇지 않은 신규 자동화 글의 기본 목표는 자체검수 후 공개 발행이다. 오류가 남으면 발행하지 않고 사유를 기록한다.

## 원고와 네이버 표시
- 3초 요약, 핵심 답 선제시, 실행 가능한 교통·요금·운영·막차·예약 정보, 짧은 모바일 단락, 실제 링크를 유지한다. 제목에서 약속한 질문에 본문이 답해야 한다.
- 본문 15; 일반 강조 16+굵게; 분홍 강조 #F02C8C+16+굵게; 큰 소제목 인용구4+19+굵게 해제; 보조 소제목 인용구2. 일반 여행글의 맥락에 맞는 이모지와 빈 줄을 살린다. 소제목 번호를 자동으로 붙이지 않는다.
- `[버튼링크:...]` 문법이나 마크다운 표를 네이버 화면에 그대로 남기지 않는다. 내부링크는 실제 공개 URL을 확인한다. 사용자 경험을 지어내지 않는다.

## 이미지
- `.claude/blog-image-project-instructions-v2.md`의 V2가 최우선이다. 카드 수·삽입 위치·비율·문구는 area1/area2와 1:1로 대조한다.
- 실제 장소 원본을 직접 입력하고 사진과 출처·라이선스를 카드별로 확인한다. 원본과 다른 풍경을 생성하지 않는다. 같은 배경 반복 대신 사용권이 확인된 다른 실사진을 찾는다.
- 글라스패널, 국소 미백, 뿌연 그라데이션, 글로우를 쓰지 않는다. 배경 보존 실패 2회면 V2의 축소 편집/원본 삽입 fallback을 따른다. 사진에 글자 오버레이가 금지된 Type3 등은 무편집 원본으로만 다룬다.

## 기록과 완료 판정
- Git 원고 완성, 네이버 임시저장, 실제 공개 발행을 구분한다. Git 커밋만으로 발행했다고 쓰지 않는다.
- 실제 발행 확인 시 공개일·제목·폴더·URL(확보 시)을 PUBLISHED-REGISTRY에 기록하고 해당 STATUS도 갱신한다. 미확인 URL·시각은 만들어내지 않는다.
- 완료 보고는 제목, 실제 확인한 발행/임시저장 상태, 확인 시각, 남은 예외만 짧게 적는다.
