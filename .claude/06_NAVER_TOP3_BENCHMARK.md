# 06 NAVER TOP3 BENCHMARK
개정: 2026-10-07. 역할: 새 여행글의 검색의도·차별화 질문 분석. 우선순위는 MASTER §2, 실행은 03, 검수는 04를 따른다.

## A. 언제 실행하나
신규 여행글 작성 또는 기존 미발행 원고의 대폭 보강 시 본문 확정 전에 실행한다. 사용자 시작신호 한 번으로 수행하며 매번 벤치마킹 승인을 묻지 않는다.
단순 오탈자, 이미 발행된 글의 작은 형식 수정, 이미지 한 장 수정은 재실행하지 않아도 된다. 비적용이면 STATUS에 작업 범위와 이유만 남긴다.

## B. 검색어 선정
글의 주 검색 질문을 기준으로 실제 네이버 검색을 한다. 검색어를 무작정 늘리지 않고 아래 순서로 필요한 것만 사용한다.
1. 제목의 주 키워드(제목은 아직 잠정안)
2. 독자가 실제 답을 찾는 핵심 질문
3. 필요 시 계절/행사 검색어

예: 무주 가볼만한곳 / 무주 덕유산 곤돌라 / 덕유산 곤돌라 요금 / 덕유산 단풍. 예시 전부를 매번 검색하라는 뜻이 아니다.
주 검색어를 우선하고 보조 검색어는 다른 의도를 확인할 때만 추가한다. 검색어별 결과를 구분하며 여러 검색어의 결과를 하나의 순위로 합치지 않는다.

## C. 상위 3개 선정
네이버 실제 검색 결과에서 동일 검색 의도를 가진 블로그 글 상위 3개를 열어 읽는다. 모두 **확인 당시 상위 노출 후보**이며 절대 순위·정답이 아니다.
- 광고/스폰서 콘텐츠는 별도 표시하고 일반 노출과 구분한다.
- 카페/지식iN/쇼핑/플레이스를 블로그 상위 글로 섞지 않는다.
- 같은 글의 중복 노출은 한 개로 계산한다.
- 검색 결과 위치가 명확하지 않으면 순위를 지어내지 않는다.
- 개인화·기기·로그인·시점에 따라 달라질 수 있음을 기록한다.
- 확인시각은 날짜·시각·KST를 포함한다. 검색 화면/영역, 검색 URL, 확인 가능한 로그인·기기 조건도 기록한다.
- 다른 검색엔진의 결과나 site: 검색만으로 네이버 표시 순서를 증명하지 않는다.

각 글 기록:
- 확인 당시 검색어, 실제 표시 순서/영역(불명확하면 미확인), 광고/스폰서 표시 여부
- 제목, 블로그명, 게시일/수정일(보이면), URL
- 대표이미지 성격
- 첫 3~5줄의 접근 방식(문장 인용 대신 방식 요약)
- 주요 소제목의 주제(배열을 복제하지 않고 요약)
- 강하게 답하는 질문, 사진 종류·구성
- 교통/요금/운영시간/코스/맛집 등 정보 깊이
- CTA/내부링크 여부

보이지 않는 항목은 미확인으로 둔다. 검색 스니펫만 읽고 본문을 읽었다고 하지 않는다. 접근 불가 항목을 “빠진 답”으로 단정하지 않는다.
전체 본문·경쟁 사진을 복사하거나 저장하지 않는다. 제목·URL 등 최소 식별정보와 자체 분석 요약만 작업기록에 남긴다.

## D. 반드시 하는 분석
### ① 공통점
세 글이 모두 다루는 항목을 추출한다. 예: 곤돌라 요금, 단풍 풍경, 주차, 향적봉.
검색자가 기본적으로 기대하는 정보로 보고 우리 글에도 필요한 항목을 빠뜨리지 않는다. 두 글만 다룬 내용은 세 글의 공통점이라 기록하지 않는다.

### ② 강점
각 글의 특별히 좋은 점을 구체적으로 기록한다. 예: A 사진 / B 구체적 시간표 / C 이해하기 쉬운 이동 동선.
우리 글에서 이미 더 잘하는 질문·형식은 유지한다. 검색 상위라는 이유만으로 우리 성과가 입증된 형식을 교체하지 않는다.

### ③ 빈칸
**세 글을 모두 읽어도 제대로 해결되지 않는 질문**을 찾는다. 글별 누락과 세 글 전체의 미해결 질문을 구분한다.
예:
- 65세 할인은 어떻게 적용되는가
- 주말 사전예약은 언제 열리는가
- 상행/하행 마감은 어떻게 다른가
- 버스터미널에서 곤돌라까지 실제로 어떻게 가는가
- 향적봉까지 꼭 걸어야 하는가
- 돌아오는 막차는 몇 시인가
- 쉬는 곳은 어디인가
- 무릎이 약하면 어디까지만 보면 되는가

공식 근거로 정확히 답할 수 있는 빈칸을 핵심 차별화로 선택한다. 질문마다 공식 취재 대상 → 채택 근거/적용 조건 → 본문에서 답할 위치를 연결한다.
확인할 수 없는 숫자를 만들지 않는다. 해결 못한 질문은 제목 약속에서 빼고 미해결로 기록한다. 확인 가능한 공통 빈칸이 없으면 억지로 만들지 않고 우리 성과·공식 취재에서 입증 가능한 차별점을 선택한다.

## E. 베끼기 금지
절대 금지:
- 상위 글 문장 복사
- 제목 어순만 살짝 바꾸기
- 소제목 배열 그대로 복제
- 사진 다운로드·재사용
- 개인 체험을 우리 경험으로 바꾸기
- 고유 표현/비유/후기 복제

허용: 검색의도, 독자 질문, 빠진 정보, 상대적 정보 깊이, 사진 종류/구성 방식, 제목이 약속하는 질문 분석.
최종 글의 사실·표현·사진은 공식 자료, Git 취재자료, 허용된 사진 소스와 자체 작성으로 만든다. 경쟁 글의 시간표·요금은 사실 확정 근거로 사용하지 않는다.

## F. 제목 결정 방식
TOP3 분석 후, 최신 사실 검증으로 입증된 차별점을 기준으로 제목을 확정한다.
**검색 키워드 + 상위 글의 빈칸 + 실제로 증명 가능한 차별점**을 조합한다.
단풍 풍경·곤돌라 체험 위주 글의 빈칸이 할인/예약/마지막 셔틀이어도 모두 제목에 넣지 않는다. 한 가지 강한 질문만 약속하고 나머지는 본문에서 해결한다.
제목 3안·검색 질문·근거 등 기존 제작 규칙은 유지한다. 순위를 성공 보장으로 해석하지 않는다.

## G. 홈판 적용
TOP3는 본문 품질과 검색의도용이다. 홈판 첫 화면은 별도로 점검한다.
- 제목만 보고 무슨 글인지 바로 이해되는가
- 대표이미지가 여행 가고 싶게 보이는가
- 긴 정보판처럼 보이지 않는가
- 첫 2~3줄이 독자의 관심을 잡는가
- 제목과 대표사진의 계절/장소/내용이 일치하는가

대표는 긴 정보표보다 실제 여행 풍경 중심. 02의 권리·사실성·생성 표시와 05의 디자인 참조를 유지한다. 계절 풍경을 실제 현황으로 오인시키지 않는다.
본문은 교통·요금·시간·막차·예약·쉬는 곳·시니어 실제 이동정보를 깊게 제공한다.
**입구는 여행 콘텐츠처럼, 본문은 실제로 도움이 되는 정보글처럼** 운영한다. 01의 도입·대표·3초요약 순서를 변경하지 않는다.

## I. 실패 대응
네이버 결과를 정상 확인할 수 없으면 순위를 추측하거나 가짜 1·2·3위를 만들지 않는다.
가능한 결과만 분석하고 **TOP3 확인 불가**와 확인 개수·사유·확인시각을 기록한다. 부분 확인은 세 글 전체의 빈칸이 입증된 것처럼 쓰지 않는다.
공식 취재와 기존 성과 데이터로 작성은 계속한다. TOP3 실패만으로 전체 자동화를 중단하거나 사용자에게 매번 승인 요청하지 않는다.
단, 공식 사실·핵심 교통 검증 실패는 별개다. TRANSPORT-FACT-CHECK 및 04의 기존 발행 보류 조건을 우회하지 않는다.

## J. 기존 성과 활용
.claude/performance/README.md 및 실제 블로그의 기존 성과 기록을 함께 본다. 접근 불가 통계를 추정하거나 점수로 대체하지 않는다.
우선순위:
1. 우리 블로그에서 이미 성과가 입증된 질문/형식
2. 현재 네이버 상위 글에서 확인되는 검색의도
3. 상위 글의 빈칸
4. 공식 자료로 해결 가능한 차별점

검색 상위 글을 무조건 따라가는 운영은 금지한다. 성과관리의 측정 기간·상태 구분·기존 구성 보존 규칙을 유지한다.

## K. 실행 순서에 연결
