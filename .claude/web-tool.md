# 🌐 웹취재 우회 도구 (Make) — 차단된 공식 페이지를 직접 여는 법

> 이 세션 환경은 프록시가 외부 CONNECT를 거의 다 막는다(`EGRESS_BLOCKED`).
> 기자 에이전트의 WebFetch도 `korail.com`·`*.go.kr` 같은 **1차 공식 도메인에서 자주 막힌다.**
> 그때 이 도구를 돌린다. **Make 서버에서 요청이 나가므로 이 환경의 프록시와 무관하다.**

## 언제 쓰나
- 기자가 "공식 페이지 직접 열람 실패(C등급)"로 보고한 값이 있을 때 — **요금·운영시간·매표마감**은 C등급으로 발행하면 안 된다.
- 지자체 관광 페이지(`*.go.kr`), 시설관리공단(`*.or.kr`) 같은 정적 HTML에 특히 잘 먹는다.

## 시나리오
`🌐 웹페이지 가져오기 (취재 우회)` — id **6177668** (on-demand)
데이터스토어 `🌐 웹취재 임시 (WEB)` — id **146191** / 데이터구조 **489222**

```
1 ParseJSON   {"list":[{"k":"키","u":"URL","q":"찾을 단어"}, ...]}
2 Iterator
3 HTTP        GET · parseResponse:false · 브라우저 User-Agent
5 AddRecord   146191 에 저장
```

`AddRecord`가 저장하는 값 — 태그를 지우고 **`q`가 처음 나오는 자리부터 1,800자**만 잘라 담는다.
```
keyword    : {q}_at{위치}_len{전체길이}      ← at-1 이면 그 단어가 없다는 뜻
measuredAt : 잘라낸 본문
```

## ★반드시 지킬 것 (실제로 겪은 함정)

1. **`<script`가 든 정규식을 blueprint에 넣으면 Cloudflare가 403으로 막는다.**
   WAF가 XSS로 오인한다. 태그 제거는 `"/[<][^>]*[>]/g"` 형태로 쓴다.
2. **`util:SetVariable2`는 파라미터 검증에서 자주 실패한다**(`Validation failed for 2 parameter(s)`).
   변수 모듈을 두지 말고 **표현식을 AddRecord에 인라인**한다. 길어져도 그게 안전하다.
3. **새 데이터스토어는 데이터구조를 붙이기 전엔 필드가 안 보인다.**
   레코드는 저장되는데 `data:{}`로 나온다. `data-structures_create` → `data-stores_update`로 구조를 붙이면 그때 보인다.
4. **URL을 추측하지 말 것.** 404 하나면 시나리오가 통째로 멈춘다(sequential).
   검색으로 존재가 확인된 URL만 넣는다.
5. **JS 리디렉션 페이지는 빈손이다.** `len`이 200~300자면 `location.replace(...)`만 받은 것이다.
   그 사이트는 이 방법으로 안 되니 다른 경로를 찾는다.
6. **데이터스토어는 1MB 상한.** 다 쓰면 읽은 레코드를 지우고 진행한다.

## ★2026-09-09 남원 취재에서 새로 겪은 것 (도구 개선 + 실패 기록)

**개선 — `toString()`으로 감싸라.** 사이트가 응답을 바이너리 버퍼로 주면
`replace`/`indexOf`가 `'{buffer}' is not string or number`로 죽는다.
→ AddRecord 표현식을 전부 **`replace(toString(3.data); ...)`** 로 쓴다. 지금 시나리오에 반영돼 있다.

**실패한 호스트 3곳 (원인이 각각 다르다 — 블라인드 재시도 말고 원인부터 보라)**
| 호스트 | 증상 | 원인·대응 |
|---|---|---|
| `www.gwanghallu.or.kr` | `HPE_INVALID_CHUNK_SIZE: Invalid character in chunk size` | 서버의 chunked 응답이 깨졌다. gzip을 꺼도 안 된다. **이 호스트는 포기** |
| `www.namwon.go.kr` | `400 Bad Request` | 어제 성공한 설정(gzip on·UA만) 그대로인데도 400. 지자체 WAF가 Make를 막는 것으로 보인다 |
| `tour.jb.go.kr` | 200 수신(584KB)인데 **찾는 단어가 at-1** | 본문이 JS로 그려진다. 아래 '안 되는 것'의 JS 사례와 동일 |

★**`*.go.kr`이 전부 뚫린다고 생각하지 마라.** 설악케이블카(`co.kr`)는 뚫렸지만 남원시는 400이었다.
2~3번 시도해서 원인이 서버 쪽이면 **미확보로 남기고 진도를 나간다.** 여기서 시간을 태우면 원고가 안 나온다.

## ★2026-09-10 정읍에서 추가 확인 — 사이트빌더 기반 공식 홈은 전부 실패

`naejangsancablecar.com`(내장산케이블카 공식)은 200으로 열리고 **본문이 307,197자**나 되는데
실제 값은 **0건**이었다. `요금`으로 찾으면 CSS 안에, `운행`으로 찾으면 메타 keywords 안에 걸린다.
→ **CreatorLink·윅스·아임웹 같은 사이트빌더로 만든 홈페이지는 본문이 JS로 그려진다.**
　`len`이 크다고 성공이 아니다. **찾는 단어 주변에 CSS(`{`, `px`, `font-family`)가 보이면 실패**다.

★**누적 3연패**: 국립수목원(JS 리디렉션 껍데기 100자) · 광한루원(chunked 깨짐) · 남원시(400) ·
전북관광(JS) · 내장산케이블카(사이트빌더 JS). **뚫린 건 설악케이블카(정적 HTML) 하나뿐이다.**
→ **정적 HTML을 쓰는 옛날식 공식 홈에만 통한다**고 보는 게 맞다. 2~3회 시도해서 안 되면 미확보로 넘기고 진도를 뺀다.

## 안 되는 것 (정직히)
- **네이버지도** — JS로 그리는 화면이라 HTML을 받아도 값이 없다. **마지막 1구간·맛집 가격은 여전히 운영자가 확인해야 한다.**
- **코레일 시간표** — 세션·조회 폼이 필요해 GET 한 번으로 안 나온다.
- Cloudflare 챌린지가 걸린 사이트(예: `cwg.go.kr` 경유 프록시) — `Just a moment...`만 돌아온다.

## 자격증명
이 시나리오는 **인증이 필요 없다**(공개 페이지 GET). 키를 넣을 일이 없고, 넣어서도 안 된다.

## ★2026-09-10 정읍 — **이 도구로 A등급을 처음 뚫었다**

세 편 연속 A등급 0건이었는데, 정읍에서 **한국관광공사 공식 여행기사**를 열었다.
```
https://korean.visitkorea.or.kr/detail/rem_detail.do?cotid=14d23a6e-f91a-461e-a06b-f8548b9c2a64
```
`len68803` — 태그를 지운 본문이 68,803자로 통째로 들어왔다. **정적 렌더 JSP라 잘 먹는다.**

여기서 나온 값이 원고의 오류를 잡았다.
- 초고가 `171번 약 30분`이라고 썼는데 공식은 **"버스를 타면 45분, 택시 20분"** → 40~45분으로 정정
- **"배차 간격이 긴 편이라 택시를 추천"** — 공식이 배차가 드물다고 인정한 문장
- **내장산 입산 시간 4~10월 04:00~16:00 · 11~3월 05:00~15:00** — 매표·입장 마감 계열 값

### ★교훈 — 지자체·시설 공식만 노리지 말 것
`knps.or.kr`·`naejangsancablecar.com`은 이번에도 못 뚫었다(WAF·사이트빌더 JS).
그런데 **`korean.visitkorea.or.kr`(한국관광공사)에 같은 값이 A등급으로 들어 있었다.**
→ **공식 1차가 막히면 한국관광공사 '대한민국 구석구석' 여행기사를 먼저 친다.**
　검색으로 `<지역> 뚜벅이` / `<지역> 당일치기 코스`를 걸면 해당 기사 URL이 나온다.

### `q`(찾을 단어) 고르는 요령
`at-1`은 그 단어가 없다는 뜻이다. 이번에 `셔틀`·`매표소`는 `at-1`이라 빈손이었고
`171`만 `at894`로 잡혀 본문을 끌어왔다. → **문서에 실제로 있을 법한 짧은 고유값(노선번호·시설명)을 q로 준다.**
한 URL에 q를 3~4개 걸어 두면 그중 하나는 걸린다(비용도 싸다).

## ★2026-09-11 안동 — 뚫린 것과 막힌 것

**뚫렸다**
- `https://www.maskdance.com/` (안동국제탈춤페스티벌 공식) — **len 18,678, 메인에서 날짜를 그대로 읽었다.**
  `2026. 9. 24 ~ 10. 4` · `9. 25.(금) 18:00~, 개막식` · 장소 `중앙선 1942 안동역, 탈춤공원, 원도심, 하회마을 등`
  ★**EUC-KR 사이트라 한글은 `�`로 깨진다. 그런데 숫자·날짜·시각은 ASCII라 멀쩡히 읽힌다.**
  → **한글이 깨졌다고 실패로 보지 마라.** 우리가 필요한 건 대개 숫자다. 깨진 글자 사이에서 숫자만 건져도 A등급이다.
- `https://www.tourandong.com/` — len 86,641로 열렸다. 다만 **메인에 시각표·요금이 없다**(`210` at-1). 하위 페이지를 직접 쳐야 한다.
- `https://korean.visitkorea.or.kr/detail/rem_detail.do?cotid=...` (여행기사) — 정읍에 이어 또 성공. **기사 본문이 통째로 들어온다.**

**막혔다**
- `https://www.hahoe.or.kr/` — **ECONNRESET**. `rejectUnauthorized:false`로 낮춰도 같았다.
  ★**ConnectionError는 `handleErrors:true`로도 안 넘어간다. 시나리오가 통째로 죽고 레코드가 0건이 된다.**
  → 한 호스트가 ECONNRESET을 내면 **그 URL만 빼고 다시 돌린다.** 리스트 앞쪽에 두면 뒤 항목까지 전부 날린다.
- `https://korean.visitkorea.or.kr/detail/ms_detail.do?cotid=...` (**여행지 상세**) — len 51,222로 열리긴 하는데
  `이용시간`·`65세`·`210`이 **전부 `at-1`**이다. 요금·운영시간 표가 정적 HTML에 없다.
  → ★**`rem_detail.do`(여행기사)는 되고 `ms_detail.do`(여행지 상세)는 안 된다.** 기사 쪽을 노려라.

안동 46번은 노선 개편으로 **폐지돼 210번**이 됐다. **공식 페이지도 연식을 본다.**
