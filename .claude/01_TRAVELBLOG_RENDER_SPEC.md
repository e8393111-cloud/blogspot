여기서 pt는 사용자 지정 크기 명칭이다. 네이버 편집기에서는 크기 **15 / 16 / 19**를 선택한다. 공개 DOM은 같은 크기를 15px / 16px / 19px로 표시할 수 있으므로 CSS pt→px 환산으로 글자를 키우지 않는다. 수치 검수는 편집기 크기 선택값 또는 공개글의 해당 텍스트 노드 스타일로 한다. 부모 문단의 크기만 읽어 판정하지 않는다. 굵게는 자식 b/strong까지 확인한다.

긴 문단 금지. 모바일에서 의미 단위 2~4줄로 끊고 덩어리 사이 빈 줄 1개를 기본으로 둔다. 화면 폭에 따른 자동 줄바꿈까지 기계적으로 고정하지 않는다. ✅·★ 및 글감에 맞는 이모지를 유지한다. 글꼴 이름은 임의로 새로 지정하지 않고 기존 네이버 본문 설정을 유지한다.

## 상단과 전체 순서
제목 → 도입 3~5줄 → 대표이미지 → 📌 3초 요약 → 본문.
요약에는 핵심 교통·요금·주의점을 담는다. 큰 소제목은 숫자 접두사 없이 글감에 맞는 이모지와 문구만 표시한다.
본문 각 절: 큰 소제목 → 핵심 답과 짧은 설명 → 관련 공식 링크·장소카드·사진.
마지막 정리 → 관련 있는 함께볼 여행글 → 필요한 출처/해시태그 정리 → **CTA(본문 맨 마지막)**. 네이버가 별도 표시하는 태그·공감 UI는 본문 순서에 포함하지 않는다.

승인된 소제목 형식을 유지한다. 새 Work 판단으로 번호, 볼드, 다른 인용구, 다른 크기를 적용하지 않는다. 본문 절차의 번호형 목록과 소제목 숫자는 구분한다.

## 공식 링크
- raw URL 단독 노출 및 작업용 `[버튼링크:...]` 노출 금지. Git 작업 마크업은 표시 문구와 링크 속성으로 변환한다.
- **2026-09-29 사용자 지정 기본:** 관련 문단 → `🔗 짧은 설명 문구` → 네이버 편집기 **링크 버튼**으로 URL을 입력해 만든 **네이티브 미리보기 카드** 순서. 첨부 강릉 화면의 썸네일·제목·설명·도메인이 있는 카드 형태를 따른다. 일반 텍스트 링크만으로 임의 대체하지 않는다.
- 공식 링크와 함께볼 여행글 내부링크에 같은 기본값을 적용한다. 카드의 도메인 자동 표시는 raw URL 단독 노출 금지에 해당하지 않는다. 가짜 카드 이미지/HTML로 대체하지 않는다.
- 예: `🔗 곤돌라 공식 예약·예매 안내`, `🔗 리조트 공식 셔틀 시간표`. 예시는 표시 문구이며 URL을 만들어 붙이지 않는다.
- 설명하는 문단 바로 아래 배치한다. 관련 없는 링크를 맨 아래 몰아넣지 않는다.
- 네이티브 미리보기가 오류/방화벽 문구를 반환하면 오류 카드를 남기지 말고 일반 클릭 링크로 즉시 fallback. 같은 링크 변환은 2회 실패하면 반복 금지.
- fallback은 실제 미리보기 오류/생성 실패를 확인한 경우만 허용하고 URL·실패 증상·시도 횟수·대체 결과를 STATUS에 기록한다. 정상 생성된 카드는 유지한다.
- fallback 후 표시 문구 전체에 올바른 href가 걸렸는지 확인한다. 미리보기 실패와 대상 공식 정보의 검증 실패를 혼동하지 않는다.

## 네이버 장소카드
관광지·터미널·식당·카페 등 동선에 필요한 실제 장소만 사용한다.
1. 관련 문단 아래에서 네이버 편집기의 장소/지도 검색 기능을 연다.
2. 실제 검색 결과의 **장소명 + 지역/주소**를 본문 목적지와 대조한다. 동명이면 상세 위치까지 확인한다.
3. 정확히 일치하는 결과를 선택하여 네이티브 장소카드로 삽입하고 카드 이름·주소·위치를 다시 확인한다.
4. 검색 결과가 없거나 장소명이 애매하면 카드 생략 사유를 STATUS에 남기고, 확인된 주소·가는법은 본문에 유지한다.

이미지나 임의 HTML로 가짜 장소카드를 만들지 않는다. 관련 본문 바로 아래 두고 과도하게 남발하지 않는다. 카드가 있어도 본문 주소·가는법을 삭제하지 않는다. 정확히 확인된 필요한 카드를 단순 누락하고 완료 처리하지 않는다. 모호한 장소의 정당한 생략은 04의 적용조건으로 판정한다.

## 함께볼 여행글
실제 공개 URL을 열어 제목·내용을 확인한 글만, 연결 이유 한 문장과 클릭 가능한 내부링크로 CTA 전 또는 근처에 배치한다. 제목만 덩그러니 두지 않는다. 작업용·추정 URL 금지. 관련성이 낮거나 실제 URL이 미확인이면 억지로 넣지 않고 사유 기록. 필요하고 검증된 내부링크가 빠진 상태를 완료로 처리하지 않는다.
