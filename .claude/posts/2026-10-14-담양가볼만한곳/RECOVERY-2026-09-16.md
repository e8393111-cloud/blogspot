# 담양 네이버 초안 복구 기준 — 2026-09-16

대상: `담양 가볼만한곳, 65세는 왜 상품권을 못 받을까요`

## 0. 상태와 범위
- 기존 네이버 임시저장본을 복구한다. 신규/중복 초안 생성 금지.
- 현재 임시저장본의 본문 구조와 사실 수정 중 이미 반영된 내용은 보존한다.
- 현재 삽입된 담양 이미지 세트는 사용자 미승인 상태다. `최종 이미지`로 간주하지 않는다.
- 공개 발행 금지. 복구 완료 후에도 임시저장까지만.

## 1. 네이버 실제 표시 서식 — 최우선
프로젝트의 `01-blog-image-project-instructions-1-.md`에 있는 여행글 서식을 그대로 적용한다.

- 본문: 15, 기본 굵기
- 일반 굵은 강조: 16 + 굵게
- 분홍 강조: `#F02C8C` + 16 + 굵게
- 큰 소제목: 네이버 **인용구4(quotation_underline)** + 19 + 굵게 해제
- 보조 소제목: 네이버 **인용구2(quotation_line)**
- 3초요약/안내영역/✅/★/이모티콘/짧은 단락과 빈 줄은 원래 구조대로 유지
- 글씨 크기만 키워서 소제목처럼 흉내 내지 말고 실제 인용구4를 적용한다.
- 러닝글 전용 배경 하이라이트 색 `#F4D400`을 여행글에 자동 적용하지 않는다. 여행 공개글에서 실제 확인된 하이라이트만 복제한다.

## 2. 담양 소제목 표시 규칙 — 사용자 최신 확정
**네이버에 보이는 큰 소제목 앞에는 숫자를 넣지 않는다.**
Git 원고의 `1.`, `2.` ... 번호는 작성용 구조 표식으로만 보고 네이버 표시에서는 제거한다.
이모지는 유지한다.

표시 제목은 아래 7개로 고정:

- `🚌 담양, 차 없이 가려면 어디서 어떤 버스를 타나요?`
- `🎫 죽녹원 입장료, 65세는 얼마인가요?`
- `🍂 메타세쿼이아길 입장료를 상품권으로 돌려준다는데, 65세도 받나요?`
- `⏰ 10월과 11월, 문 닫는 시간은 어떻게 확인하나요?`
- `🚏 죽녹원에서 메타세쿼이아길까지, 어떻게 이동하나요?`
- `🍜 죽녹원 국수거리, 뭘 먹으면 좋을까요?`
- `♿ 걷기 편한가요? 쉬어갈 곳은 어디 있나요?`

숫자를 제거한 뒤 인용구4 + 19 + 굵게 해제로 다시 확인한다.

## 3. 링크 복구 규칙
- `[버튼링크:이름|URL]` 문자를 그대로 남기지 않는다.
- raw URL만 덩그러니 보이는 상태를 완성으로 보지 않는다.
- 관련 문단 바로 아래 `🔗 짧은 안내명`을 두고 실제 URL을 네이버 **네이티브 링크 미리보기**로 변환한다.
- 정확한 URL이 확인된 링크만 삽입한다. 미리보기 실패 시 정확한 클릭 링크 + 짧은 안내를 유지하고 실패를 기록한다.
- 기존 여행글 내부링크는 실제 공개 URL이 확인된 경우에만 사용한다.

우선 링크:
- 고속버스 통합예매
- 시외버스 통합예매
- 죽녹원 공식 홈페이지
- 담양군 문화관광 메타세쿼이아길 안내
- 담양군 버스정보
- 담양군 공식 블로그의 친환경 시티투어 운행 중단 안내

## 4. 본문 복구 체크
최신 `area1.md`의 사실 수정 내용을 기준으로 한다.
특히 다음이 남아 있으면 고친다.

- 3초요약: `시티투어버스 또는 택시` → `당일 버스편 조회 또는 택시`
- `65세 미만 동행` → `유료 입장 대상 동행`
- 2024-01-01부터 중단 안내된 친환경 시티투어를 현재 운행 중인 것처럼 안내하지 않는다.
- 죽녹원↔메타세쿼이아길: 당일 일반버스/보행경로 확인, 시간이 안 맞으면 택시
- 외곽 소쇄원·창평·담양호: 현재 일반버스와 귀환편 별도 확인
- 담양 오드: `[신상]`, 2025 하반기 신규, 좌석 넉넉 등 미확인 표현 제거
- 상품권: `계속 시행 중` 단정 금지. 방문일 적용 조건·가맹점·사용기한 확인
- 신분증: 65세 무료입장 확인용으로만 안내

## 5. 이미지 전면 재검토 — 기존 세트 승인 금지
현재 네이버에 들어간 7장은 사용자에게 시각적으로 승인되지 않았다. 그대로 최종 처리하지 않는다.
새 이미지는 `area2.md`의 실제 CC BY-SA 원본 소스와 라이선스 조건을 유지하되 아래처럼 **텍스트를 대폭 줄여** 다시 제작한다.

### 공통 디자인
- 사용자 제공 `무릉별유천지 입장권` 카드의 타이포 위계를 기준으로 한다.
- 사진 비중 약 75~80%, 텍스트는 핵심만. 현재 area2보다 문구를 30~50% 줄인다.
- 사진 전체를 하나의 자연스러운 장면으로 유지한다.
- 글라스패널/반투명 흰 박스/둥근 카드/글자 뒤 블러/안개/그림자/외곽선/글로우 금지.
- 텍스트는 사진의 실제 밝은 여백(하늘·길·테이블)에 직접 올린다.
- 제목은 단정하고 탄탄한 현대적 고딕. 광고용 블랙체처럼 과도하게 굵지 않게.
- 정보 본문은 중간 굵기 고딕. 핵심 숫자/한 줄만 러셋 브라운 `#7A4A2F`.
- 짧은 감성 보조문구 1줄만 손글씨 허용. 시간/요금/전화/노선에는 손글씨 금지.
- 사진 자연색과 중성 화이트밸런스를 유지하고 전체를 갈색 필터로 물들이지 않는다.
- 원출처/라이선스 표기와 `blog.naver.com/witchbloom82` 워터마크 유지.

## 6. 네이버 복구 순서
1. 현재 열린 기존 담양 임시저장본인지 제목 확인
2. 새 글 생성 금지
3. 소제목 7개에서 숫자만 제거 → 인용구4/19/굵게해제 적용
4. 본문15 복구
5. 원고의 `[굵게]`와 `[색변경]` 위치를 16 굵게 / #F02C8C 16 굵게로 구현
6. 3초요약·안내박스·✅·★·빈 줄을 원래 구조대로 확인
7. 링크를 네이티브 미리보기로 정리
8. 현재 이미지 세트는 승인하지 말고 새 이미지가 준비되기 전까지 임의 대체/재생성 금지
9. 모든 항목을 화면에서 육안 확인한 후 임시저장
10. 임시저장 목록에서 최신 시각 확인 → 같은 저장본 재열기 → 소제목·본문·강조·링크 유지 확인

## 7. 실패 규칙
- 같은 UI 동작 2회 실패 시 중단.
- 실패한 한 항목 때문에 이미 정상 적용된 다른 서식을 다시 뜯지 않는다.
- 저장 전 실패했다면 현재 편집 내용을 먼저 안전하게 임시저장 가능한지 확인한다.
- 완료 여부를 추정하지 않는다. 실제 저장 목록과 재열기까지 확인해야 완료다.
