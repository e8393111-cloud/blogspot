    축제/행사/전시 안내

    행사명 : 2026 청남대 '가을축제'

    • 행사기간 : 2026년 10월 31일(토) ~ 2026년 11월 8일(일)
    • 요약 : 국화분재 / 목·석부작 / 바위솔 / 수목분재 / 문화·예술공연 / 체험 / 이벤트 / 문의면 농특산물 홍보판매장
    상세내용

    2026 청남대 가을축제 


    Ⅰ. 행사 개요


      1. 행  사  명 : 2026 청남대 '가을축제'

      2. 기       간 : 2026. 10. 31.(토) ~ 11. 8.(일) / 9일간

                           ※ 축제기간 월요일 정상개관 - 휴관 없이 운영

      3. 운영시간 : 09:00 ~ 18:00 (입장 마감 16:30)

                            ※ 축제기간 토요일 21시까지 야간 운영

      4. 장        소 : 충청북도 청주시 상당구 문의면 청남대 일원

      5. 주        최 : 충청북도 청남대관리사업소


    II. 주요 내용


      1. 전 시 

        - 국화분재 (청남대기념관)

        - 수목분재/ 바위솔 /목석부작 작품전시 (헬기장)

       

      2. 체험·판매

        - 친환경체험(4종) / 한방체험 /인생네컷 / 6차산업 / 전통 안데스 음악 등 (헬기장)

        - 목공예체험 / 영동와이너리 / 완제품 푸드존 / 편의점 등 (테니스장)

        - 문의면 농·특산물 홍보판매장 (입구 돌담) / 선사시대 전시, 체험(예정)


      3. 공 연 (어울림마당)

        - 축제기간 상설 공연 : 11:00 ~ 16:00

        - 토요일(야간 공연) : 19:00 ~ 19:30


      4. 충북예술제 개막 및 전시, 공연 행사

        - 제68회 충북예술제 개막식

          일시 : 10. 30.(금) 10:30

          장소 : 청남대 어울림마당


        - 충북예총 설치미술전 “바람의 솟을 굿”

          기간 : 10. 30.(금) ~ 11. 8.(일)

          장소 : 호수영미술관


        - 제40회 충북공예가협회 “손끝에서 충북展”

          기간 : 10. 30.(금) ~ 11. 13.(금)

          장소 : 청남대기념관 기획전시실


        - 시군예총 공연행사

          일시 : 10. 30.(금) 10:00 ~ 

          장소 : 청남대 어울림마당, 메타포레, 청남대 일대

          행사 : (청남대 일대) 조선시대 인물 포토타임 / 연극협회

                    (어울림 마당) 괴산청소년오케스트라 희망나눔연주회 / 괴산예총    

                    (어울림 마당) 제68회 충북예술제 「水놓아 아우르는 국악향연」 / 영동예총

                    (어울림 마당) 음성예총 음성예술단 공연 / 음성예총

                    (어울림 마당) 국악의 멋, 가요의 흥 / 제천예총

                    (어울림 마당)보고, 듣고, 반하다 : 진천 스토리 퍼포먼스 / 진천예총

                    (메타포레) 수류화개(水流花開) : 소리의 물길, 예술로 피어나다 / 국악협회

                    (메타포레) 메타포레 버스킹공연 / 충북예총


        - 충북연예예술인 “열린 뮤직 페스타”

          일시 : 10. 31.(토) 14:30, 15:30

          장소 : 청남대 메타포레


    III. 주말 무료 순환버스 운영 안내


      1. 운행일자 : 가을축제 기간 주말 (10월 31 / 11월 1, 7, 8) 4일간   

      2. 운행시간 : (문의문화유산단지 출발) 첫차 - 09:20 막차 - 16:00

                            (청남대관리사업소 출발) 첫차 - 10:00 막차 - 18:00

      3. 승하차장 : 문의문화유산단지(출발) - 문의초등학교입구(시내버스정류장) - 노현 습지공원 - 청남대(도착)

      4. 운행요금 : 무료    ※ 순환버스 이용 관람객은 청남대 입장료 무료
