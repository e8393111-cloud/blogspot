# 02 — 여행 이미지 실행 규격
개정: 2026-09-29. 역할: **이미지를 어떻게 만들어야 하는가**. 상세 디자인 근거는 blog-image-project-instructions-v2.md, 삽입 위치는 area1/area2, 완료 검수는 04를 참조한다.

## 시작 판단
- 최종 이미지 생성·편집은 **GPT 이미지**가 기본이자 고정 경로다. 사용자가 다른 도구를 명시한 경우 외에는 다른 생성기·외부 조판으로 우회하지 않는다.
- 실제 사진이 있으면 **그 실제 원본을 입력 이미지로 제공하여 편집**한다. 텍스트 설명만 넣거나 AI가 비슷한 장소를 새로 생성하는 것은 금지한다.
- **중요한 용어 구분:** `기존 원본 사용`은 기본적으로 **원본 파일을 GPT 이미지 편집의 입력으로 사용한다**는 뜻이다. `원본 그대로 삽입`과 같은 뜻이 아니다.
- 변경 가능한 Type1/CC 등 소스이고 area2에 카드 문구가 지정되어 있으면 기본 상태는 `EDIT`다. 실제 원본을 그대로 네이버에 올리고 이미지 작업 완료로 처리하면 안 된다.
- `RAW(원본 그대로)`는 ① Type3/변경금지, ② 현재 편집 사이클에서 실제 원본 왜곡이 2회 확인된 fallback, ③ 사용자가 명시적으로 '원본 그대로'를 요청한 경우에만 허용한다.
- 원본을 직접 열어 장소·장면·계절과 사진별 권리를 확인한다. 실제 사진이 없으면 사용 가능한 실사진부터 확보한다. 없다는 이유로 가짜 풍경을 만들지 않는다.
- 사용자 비승인 이미지는 재사용하지 않는다. 자체검수 통과와 사용자가 승인한 장기 스타일은 별도 상태다.

## 허용 / 금지
허용(변경 가능 라이선스에 한함): 크롭, 리사이즈, 밝기·대비·채도·색온도 미세 보정, 텍스트, 워터마크, 출처 추가.

금지:
- 하늘 재생성, 산·나무·꽃·건물·사람 추가/삭제/교체, 계절·날씨 변경.
- 길·버스·표지판·정류장·시설 생성, 꽃·단풍·눈 과장, 관광지 실제 모습 왜곡.
- 흰 안개, 국소 미백, 글로우, 큰 반투명 패널, 흰 박스, 글라스 패널, 정보 띠.
- 그림자·외곽선 효과(과한 그림자 포함), 과한 HDR·채도, 광고 배너 느낌.
- 글자 자리를 만들기 위한 배경 재창작. 가독성은 자연 여백·글자 위치·색·줄바꿈으로 해결한다.

## 대표이미지 / 기본 비율
대표는 실제 여행사진이 화면 대부분을 차지한다. 장소 풍경을 먼저 보여주고 문구는 짧게. 여행 매거진/엽서 느낌으로, 정보카드·광고처럼 보이지 않게 한다. 홈판에서 눌러보고 싶은 실제 장면을 우선하되 클릭률을 보장한다고 말하지 않는다.

| 용도 | 비율 |
|---|---|
| 썸네일 | 1:1 |
| 일반 정보카드 | 4:5 |
| 숫자·요금 카드 필요 시 | 3:4 허용 |
| CTA | 16:9 |

원본 그대로 쓰는 fallback과 Type3는 원본 비율을 유지한다. 하위 area2의 상충하는 비율·패널 지시는 이 규격에 맞춰 정리한다. 카드 문구·숫자는 검증된 본문과 대조한다. 같은 배경을 반복해 개수를 채우지 않는다.

## 골든샘플 디자인 실행 규격 — 2026-09-29 사용자 피드백 반영
- 이미지 디자인 기준은 05에 기록한 **강릉 대표이미지·마지막 CTA의 타이포그래피와 정보 위계**다. 해당 글 전체의 모든 사진·효과를 승인한 것으로 확대하지 않는다.
- 실제 장소 원본과 디자인 레퍼런스를 둘 다 직접 열고 편집 입력으로 제공한다. 입력1=보존할 실제 원본, 입력2=글자 배치·굵기·위계만 참고할 골든샘플. 입력2의 배경·사람·계절·시설을 입력1로 옮기지 않는다.
- 원본 보존만 통과한 결과는 디자인 완성본이 아니다. **원본 보존 / 디자인 일치 / 문구·가독성**을 별도로 YES/NO 판정하고 모두 YES일 때만 게시한다.
- “사진이 주인공”은 핵심 문구를 작은 워터마크 크기로 줄이라는 뜻이 아니다. 작은 것은 블로그 워터마크이며, 제목·CTA는 독자가 바로 읽을 수 있어야 한다.
- 아래 수치는 샘플의 정확한 폰트 실측값이 아니라 이번 피드백을 실행하기 위한 **제작 시작 범위**다. 최종 판단은 동일 표시 크기의 실제 샘플과 시각 비교한다.

| 항목 | 제작 기준 |
|---|---|
| 대표 1:1 | 자연 여백의 왼쪽 위에 짧은 제목2줄을 기본으로. 탄탄한 고딕, 제목 아래 보조문구1줄. 사진의 주요 대상 가리지 않기 |
| 대표 제목 | 글자 높이 약 이미지 폭의9~12%부터 시작. 보조문구는 제목의30~40% 크기. 긴 제목을 작은 한 줄로 욱여넣지 않기 |
| CTA16:9 | 자연 여백의 왼쪽 또는 왼쪽 위에 제목과 보조문구. 제목 글자 높이 약 이미지 폭의6~8%, 보조문구는 제목의35~45%부터 시작 |
| CTA 문구 | “공감 💗 + 이웃추가” / “뚜벅이 당일치기 코스 꾸준히 올려요”. 하트를 임의로 누락하지 않기 |
| 정렬·여백 | 같은 텍스트 블록 안의 왼쪽 기준선 통일. 좌우 안전여백 약6~10%. 제목과 보조문구 사이 충분한 간격 |
| 색·장식 | 밝은 자연 여백에는 짙은 잉크색. 어두운 여백에는 밝은 글자. 포인트색1개. 샘플의 하트·가벼운 선 장식은 참고 가능하나 자동으로 늘리지 않기 |
| 워터마크 | 블로그 주소만 우하단에 작게. 관광공사 원표시와 겹치지 않기. 제목·CTA를 그 주변에 몰아넣지 않기 |
| 정보카드 | 제목→핵심값→조건 순서. 작은 글자로 긴 목록을 모두 넣지 않는다. 카드 문구가 많으면 핵심3~5항을 우선하고 나머지 조건은 본문에 보존하며 area2 대응표 갱신 |

**사진과 레이아웃의 적합성:** 원본의 자연 여백에 위 크기의 문구가 들어가는지 생성 전에 판단한다. 왼쪽 여백이 없으면 오른쪽으로 옮길 수 있으나 제목 크기·위계는 유지하고 area2에 이유를 남긴다. 하늘 생성, 시설 이동, 글자 미니어처화로 공간을 만들지 않는다. 원본 워터마크가 잘리는 크롭도 실패다.

**축소 검수:** 대표는 폭180px의 목록 크기에서 핵심 제목, 모든 카드는 폭360px에서 제목·CTA·필수 정보가 확대 없이 읽히는지 확인한다. 원본 크기에서만 읽히면 NO. 실제 네이버 적용 후에도 확인한다. 이 두 폭은 새 QA 기준이며 골든샘플의 관측 해상도라는 뜻이 아니다.

**실패 분리:** 작은 글자·잘못된 배치·스타일 불일치를 배경 왜곡 횟수에 넣지 않는다. 디자인만 실패하면 해당 요소만 수정하며, 실제 배경 왜곡2회일 때만 아래 RAW 예외를 적용한다. 실패 결과를 강제로 통과시키거나 무한 재생성하지 않는다. 불확실한 원본 일치는 YES로 올리지 않는다.


## 원본 왜곡 2회 실패 → 현재 편집 사이클 종료
같은 이미지 편집에서 원본 왜곡이 **현재 편집 사이클에서 2회** 발생하면:
1. 프롬프트 변경을 포함해 해당 이미지 재생성을 더 이상 하지 않는다.
2. 실제 원본 사진 그대로 사용한다.
3. 필요한 정보는 네이버 본문 텍스트로 이동한다.
4. 이미지 개수를 억지로 채우지 않는다.

도구를 바꾸거나 새 Work로 옮겨 횟수를 임의로 초기화하지 않는다. 다만 **사용자가 이후 명시적으로 '실제 원본을 사용해 다시 편집'이라고 재시도를 요청하면 이전 fallback은 최종 잠금이 아니다.** 새 편집 사이클로 다시 시도하되, 그 사이클도 최대 2회 왜곡 실패까지만 허용한다. STATUS에 실패 횟수·원본·최종 삽입 위치·본문으로 옮긴 정보를 기록하고 area1/area2 대응표를 갱신한다. 정보 보존 후 카드 축소는 누락이 아니지만 대표사진과 텍스트 CTA는 유지한다.

## 저작권
- 사진별 출처·원저작자·원본 URL·라이선스를 photos/CREDITS에 대조한다. 동일 사이트의 다른 사진과 권리를 혼동하지 않는다.
- Type1 등 **변경 가능한 소스만** 텍스트 오버레이. CC BY-SA 등은 해당 라이선스의 표시·동일조건 등 실제 조건을 지킨다.
- 변경금지 **Type3는 원본 그대로**. 크롭·색보정·텍스트·워터마크 추가를 하지 않는다. 출처는 본문/캡션에 표시한다.
- 관광공사/원저작자 워터마크 삭제·가림 금지. 출처·라이선스 유지.
- 권리 미확인 사진은 사용하지 않는다. 문서 우선순위로 실제 저작권 조건을 덮지 않는다.
