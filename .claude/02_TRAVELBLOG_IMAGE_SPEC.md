## 최소 이미지 수 — 2026-09-29 추가
- 다음 여행글부터 **본문에 실제 삽입된 이미지 최소 5장**. 대표와 CTA 포함; 링크 미리보기·장소카드·같은 파일 반복 삽입은 이미지 수에 포함하지 않는다.
- 기본 구성 예: 대표 1 + 서로 다른 본문 이미지 3 이상 + CTA 1. 글 내용에 맞게 용도·수량을 조정하되 5장 미만으로 임의 축소하지 않는다. 한 장 한 메시지와 배경 다양성을 유지한다.
- 개별 이미지가 실패/생략되면 다른 적합한 소스·구성으로 보충한다. 권리·사실 검수를 통과한 5장을 확보하지 못하면 부족 수와 이유를 기록하고 이미지 완료로 처리하지 않는다. 수량 때문에 권리 미확인 사진이나 허위 현장 이미지를 사용하지 않는다.
- 이번 규칙은 다음 글부터 적용. 기존 무주 3장 기록은 과거 결과이며 다음 글의 수량 기준이 아니다.

## 실행 모드
- EDIT: 변경 가능한 실사진을 실제 입력으로 제공. 크롭·색상·기울기·선명도 보정, 기존 인물/사진 속 주소·전화번호 등 불필요한 식별정보 제거, 배경 복원·확장·재구성 허용.
- GENERATE: 새 이미지가 필요하면 GPT 이미지로 생성 가능. 실사진이 없다는 이유만으로 무조건 중단하거나 RAW 사용하지 않는다.
- RAW: 변경금지 자료, 사용자 원본 요청, 편집 불필요 또는 합리적인 fallback. 이유 기록.
- OMIT: 적합한 이미지가 없을 때 생략, 필요한 정보 본문 보존.
- 시작 전 모드·원본/생성 목적·보존/변경 요소·문구·비율·위치 표시. GPT 이미지가 기본이며 실제 폰트 조판은 사용자가 승인한 범위에서 적용한다.

## 유지할 절대 조건
- 모든 패널/박스/글라스/상하단 띠 금지. 글자 뒤 흰 안개·국소 미백·블러·글로우도 금지. 글자 그림자·외곽선 금지.
- 관광공사/원저작자 워터마크·출처·라이선스 보존. 개인정보 정리와 출처 제거를 혼동하지 않는다.
- Type1 등 변경 가능 소스만 편집. Type3는 원본 유지 또는 다른 소스로 교체. 권리 미확인 사진 사용 금지.
- 생성/계절 변경/핵심 배경 재구성은 실제 촬영 현황으로 위장하지 않는다. ‘AI 생성 예시 이미지’ 또는 ‘AI 편집·연출 이미지’ 캡션을 가까이 표시. 보정·인물 제거 등 실제 적용 범위는 CREDITS에 기록.
- 관광지 위치·시설·길찾기·단풍 현황 등 사실의 근거는 별도 확인. 생성 이미지로 사실을 입증하지 않는다. 생성물에 허위 관광공사 출처를 붙이지 않는다.
