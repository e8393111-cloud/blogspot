# 정동진 열차 안내 교체안 — 발행 대기

대상: https://blog.naver.com/witchbloom82/224326561092
상태: 수정안 준비만 완료. 2026-09-12 브라우저 탭 조회 시간 초과로 편집·발행하지 못함.

## 판단 범위
기존 07:16/20:11/21:59 등 시각과 운임이 틀렸다고 확인한 것이 아니다. 현재 공식 시간표 대조에 실패했으므로 최신 확정값처럼 반복 단정하지 않도록 교체안을 준비했다. 공식 승차권 페이지 https://www.korail.com/ 는 검색에서 서비스 이용 안내만 확인되어 날짜별 편성·운임 검증 근거가 되지 못했다.

## 적용 전
공개 본문을 다시 읽어 다른 작업자의 변경 여부를 확인한다. 기존 제목·3초 요약·사진·소제목·강조 서식·장소 카드·링크는 보존한다. 관련 이미지 안의 열차 시각·운임 표기도 확인해 본문과 충돌하면 함께 보완한다. 최신 열차표를 확인할 수 있다면 이 일반 안내 대신 조회 날짜와 적용일을 명시한 검증값을 사용한다.

## 문장별 교체안

### 도입부
기존 '돌아오는 막차는 정동진 21:59, 이것만 기억하면 돼요.'
→ '돌아오는 기차부터 정해 두면 하루 동선을 짜기 편해요. 출발 전에 여행 날짜의 정동진 → 청량리 편을 먼저 확인해요.'

### 3초 요약
'▸ 첫차 07:16 / 막차(가는) 20:11 · 돌아오는 막차 21:59'
→ '▸ 예매 : 여행 날짜로 청량리 → 정동진, 정동진 → 청량리를 각각 조회'
'▸ 요금 : 기차 26,700원 (경로 평일 30% 할인)'
→ '▸ 기차 비용 : 승객 유형을 선택한 뒤 표시되는 왕복 운임으로 계산'
'▸ 조심 : 귀경 막차 21:59 / 바다부채길 기상 통제'
→ '▸ 조심 : 예약한 귀경 열차에 맞춰 역 복귀 / 바다부채길 기상 통제'

### 기차 본문 안내 목록
기존 가는 길·오는 길·소요·요금·경로 할인 목록을 아래로 교체한다.
✅ 가는 길 : 코레일에서 청량리 → 정동진, 여행 날짜를 넣고 조회해요.
✅ 오는 길 : 같은 날짜로 정동진 → 청량리를 따로 조회하고 귀경편부터 정해요.
✅ 소요 : 선택한 열차의 출발·도착 시각으로 확인해요.
✅ 요금 : 승객 유형과 좌석을 선택한 뒤 표시되는 운임을 확인해요.
✅ 경로 이용 : 경로 승객으로 조회하고 실제 할인 적용 여부를 확인해요. 신분증도 챙겨요.

기존 '앱이 어려우면 전화(☎1544-7788)로도 예매돼요.'
→ '앱 이용이 어려우면 코레일 고객센터(☎1544-7788)에 이용 가능한 예매 방법을 문의해요.'
전화 예매가 누구에게나 가능하다고 새로 단정하지 않는다.

### 방문 전 체크

→ '▸ 기차 : 여행 날짜로 왕복 조회·예매하고, 귀경 승차권의 출발 시각에 맞춰 역으로 돌아오기'

## 완료 기준
위 수정 또는 검증된 최신값 반영 → 공개 본문·이미지 수치 충돌 확인 → 기존 글 수정 발행 → 공개 반영 확인 → 해당 탭 닫기. 이 파일 생성만으로 발행 완료 처리하지 않는다.
