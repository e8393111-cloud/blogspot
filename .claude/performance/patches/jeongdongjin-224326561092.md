## 1. 3초요약 동선 한 줄 교체

기존: `▸ 동선 : 역 앞 바다 → 모래시계공원 → 레일바이크 → 바다부채길`
문제: 본문은 바다·공원·카페만으로 반나절이라고 설명하지만 요약은 유료 체험과 도보 탐방을 모두 필수처럼 연결한다.
기존 요약 박스 안에서 동선 줄만 아래 두 줄로 교체한다. 날짜·요금은 이번 구조 수정으로 검증된 것이 아니다.

```text
▸ 기본 : 정동진역 → 해변 → 모래시계공원 → 카페 → 역 복귀
▸ 선택 : 레일바이크 또는 바다부채길 — 남은 시간과 걷는 부담에 맞춰 추가
```

## 2. 기본 코스 단락 끝에 선택 기준 삽입

위치: `🌊 역 앞에서 바로 시작`의 기본 동선과 ‘바다·공원·커피만으로도 반나절’ 문장 뒤.

```text
처음 가는 날에는 기본 코스만 잡고, 체험은 하나만 더해도 좋아요.
레일바이크를 고르면 예약 회차에 맞추고,
바다부채길을 고르면 탐방을 마친 뒤 역으로 돌아오는 이동까지 일정에 넣어요.
두 곳을 모두 필수 코스로 채울 필요는 없어요.
```

## 3. CTA 앞에 실제 관련 글 연결

원주 공개 글 본문과 제목은 이번 브라우저에서 확인했다. 원주와 정동진을 같은 날 이어 가는 코스로 소개하지 않는다.
기존 CTA·해시태그·이미지는 보존한다. 네이버에는 Markdown 문법을 그대로 붙이지 말고 기존 스타일의 링크 카드로 넣는다.

```text
🔗 함께 볼 여행글

다음에는 산 풍경을 보는 기차 여행을 찾는다면,
원주 소금산 당일치기 코스도 비교해 보세요.
```

연결할 원문: https://blog.naver.com/witchbloom82/224340238227
단, 원주의 교통·운영 보강 확인을 먼저 마친 뒤 공개 연결한다. 미검증 정보를 연계해 확산하지 않는다.

## 추가 검증 항목

- 기존 KTX 열차 시각·편수·요금의 여행일 기준 재조회. 본문 표현만으로 청량리~강릉 노선이 모두 정동진을 지난다고 읽히지 않는지 검토.
- 바다부채길 매표소 위치, 역에서 실제 이동, 편도 탐방 후 복귀 동선·소요·마감·요금 검증.
- 레일바이크 운행 회차·가격·취소 조건과 ‘힘들지 않다’ 확정 표현 검토.
- 식당 주소와 ‘역 앞/오가는 길’ 주장이 실제 경로와 맞는지 확인.

이 파일은 기존 글에 대한 국소 수정안이다. 전체를 새 글로 재작성하거나 기존 서식을 제거하지 않는다.
