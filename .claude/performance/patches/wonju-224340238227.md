# 원주 소금산 — 부분 검증된 교체 문단

- 원문: https://blog.naver.com/witchbloom82/224340238227
- 제목: 원주 소금산 출렁다리 당일치기 코스, 차 없이 기차로 — 유지
- 원문 열람: 2026-09-11, 로그인된 브라우저에서 본문 확인
- 상태: 수정안 작성 및 아래 교통 항목 부분 검증. 네이버 임시저장·공개 수정은 아직 아님.
- 적용 원칙: 해당 문단 텍스트만 교체. 원본 지도·이미지·서식·나머지 소제목은 보존. 이미지에 같은 값이 있으면 대조 후 함께 수정.

## 1. 시티투어 문단 교체

위치: `🚌 원주역에서 소금산까지, 뭐가 제일 편해요?` 아래 시티투어 안내부터 서원주역 문장까지.
기존의 ‘가장 저렴’은 모든 교통수단의 실제 비용을 비교한 근거가 없어 사용하지 않는다.

```text
원주 시티투어버스는 원주역·서원주역과 소금산그랜드밸리를 연결해요.
탑승권으로 소금산 통합권 할인도 받을 수 있어요.

✅ 1일권 : 성인 5,000원 · 65세 이상 3,000원
✅ 결제 : 사전예약 없이 기사님께 현금·카드 결제
✅ 교통카드 : 결제 불가
✅ 소금산 통합권 : 시티투어 탑승권 소지 시 18,000원 → 12,000원
✅ 성인 기준 버스 1일권+할인 통합권 : 합계 17,000원

버스값과 소금산 입장료는 별도예요.
17,000원에는 기차·식사 비용이 포함되지 않아요.
탑승권은 재승차와 할인에 필요하니 잘 보관해요.

공식 시간표에서 원주역 출발은 09:20·10:40·15:40·17:00이에요.
서원주역은 각각 09:50·11:10·16:10·17:30,
소금산그랜드밸리 ‘건너편’ 정류장은 09:56·11:16·16:16·17:36이에요.
정류장 도착 시각과 매표소 도착 시각은 달라요.

전체 6회 운행 안내에는 관광지 순환 2회가 포함돼 있어요.
원주역에서 소금산으로 가는 출발편 6개로 읽으면 안 돼요.
월요일은 원칙적으로 쉬며 공휴일 예외와 별도 휴무일이 있어요.
```

공식 링크 유지/갱신: [원주 시티투어 안내](https://www.wonju.go.kr/tour/contents.do?key=6509)
출처 최종수정일 2026-08-14 / 이번 열람일 2026-09-11.
원문 후반 ‘🚌 소금산 가는 길’ 박스도 위 요금·결제와 모순이 없는지 대조한다.

## 2. 야간쇼 귀경 확정 문장 교체

위치: ‘볼 수 있는 철엔 9시쯤 끝나 막차(22:07)까지 여유가 있어, 보고 와도 당일치기가 돼요.’
교체 이유: 철도 막차만으로 공연장→역 복귀를 보장할 수 없다. 2026-09-11 열람한 공식 나오라쇼 페이지의 상단 안내 이미지 텍스트와 하단 표도 서로 다른 공연 시각을 제시한다. 어느 하나를 임의로 확정하지 않는다.

```text
나오라쇼를 추가한다면 공연장부터 역까지 돌아갈 교통편을 먼저 정해야 해요.
시티투어가 공연 종료 뒤에도 다닌다고 가정하면 안 돼요.
야간 복귀편을 정하지 못했다면 낮 관람 코스로 마무리해요.
```

검증 근거: [공식 나오라쇼 안내](https://www.wonju.go.kr/tour/contents.do?key=5518), [시티투어 시간표](https://www.wonju.go.kr/tour/contents.do?key=6509).
공연 시작·종료 확정은 운영 공지 추가 확인 필요. 기존 반복 시각과 계절 문구도 함께 대조해야 한다.

## 3. 관련 글 연결 이유 추가

기존 `🔗 같이보면 좋은글` 안의 실제 링크 두 개는 이미 존재한다. 삭제하거나 없는 것으로 기록하지 않는다.

```text
🔗 다음 기차 여행은 바다로 가고 싶다면 — 정동진 당일치기 코스
🔗 시티투어를 이용하는 다른 여행이 궁금하다면 — 무릉별유천지 당일치기 코스
```

각 문장은 기존 해당 링크 바로 앞 라벨로만 교체한다. 새로운 가까운 연계 코스처럼 소개하지 않는다.

## 전체 갱신 완료 전에 남은 항목

- 원주역·서원주역·터미널→정류장/매표소까지 도보를 포함한 실제 네이버지도 경로.
- 기존 KTX 22:07·고속버스 22:30·첫차·요금을 대상 여행일 기준 재검증.
- 낮 운영·매표·입장·탈것 마감의 별도 최신 출처. 현재 페이지 조회만으로 네 항목이 모두 확인된 것은 아님.
- 케이블카가 무릎 불편을 해결한다는 과도한 확정, 울렁다리 ‘국내 최장’ 최상급, 잔도 길이의 원문/공식 차이 검토.
- 기존 식당의 실제 도보권·영업·가격, 카드 내 같은 수치 대조.

부분 정정과 글 전체 최신화는 구분한다. 적용 전후 원문을 보존하고, 공개 수정이 확인될 때만 갱신일과 측정 시작일을 기록한다.

## 6. ★★공식 출처 두 곳이 서로 다르다 — 단정하면 안 되는 값 2건

여기가 이번 보강의 핵심 경고다. **원주시 관광 사이트와 원주시시설관리공단이 같은 시설을 다르게 적는다.**

→ **어느 쪽이 현재 매표소 실제 적용인지 이 환경에서는 판정할 수 없다.**
→ **본문에 "12,000원"을 단정으로 남기지 말고**, 매표소(☎033-749-4860)에 확인하도록 쓰거나

## 7. 최상급 표현 — 공식값으로 정리됨 [A]

기존 '남은 항목'의 `울렁다리 '국내 최장' 최상급, 잔도 길이의 원문/공식 차이`는 확인됐다.
**공식(시설관리공단·원주관광 동일)** — 울렁다리 **404m**(기존 출렁다리의 2배) · 출렁다리 **길이 200m·높이 100m** ·
소금잔도 **360m**(고도 200m 절벽) · 데크산책로 **700m** · 케이블카 **972m**(10인승 캐빈 22대).
→ **'국내 최장'이라고 쓰지 말고 위 숫자를 그대로 쓴다.** 공식 어디에도 최상급 표현이 없다.

## 8. 이번에도 못 구한 것 (지어내지 않았다)

- **원주역·서원주역·터미널 → 정류장/매표소 도보를 포함한 실제 경로** — 네이버지도가 이 환경에서 막혀 있다. 운영자 확인 몫.
- **KTX 22:07 · 고속버스 22:30 · 첫차·요금의 대상 여행일 기준 재검증** — 코레일 egress 차단.
- **케이블카·에스컬레이터의 개별 운행 종료 시각** — 공식이 시설 묶음(출렁다리·데크산책로·소금잔도·스카이타워·울렁다리)의
  운영/매표 시간만 적고 **탈것별 막차 시각은 따로 쓰지 않는다.** 매표 마감(16:30/15:30)이 사실상 마지막 시각이나,
  **'케이블카 막차'라는 별도 값이 있는지는 확인하지 못했다.** 매표소 문의 필요.
- **식당의 실제 도보권·영업·가격** — 네이버지도 필요.

## 상태

- §1 시티투어 문단 : 시각표·요금은 유지. ★단 "18,000→12,000"은 **출처 간 불일치**가 확인돼 금액 단정을 권하지 않는다.
- §2 나오라쇼 문단 : 유지 + 위 §6(2) 보강 문장 추가. **7~8월 휴장**이 새로 확인됐다.
- §3 관련 글 연결 : 변동 없음.
- §4·§5 신규 : **매표 마감**과 **네트어드벤처 회차제**를 A등급으로 확보했다.
- 네이버 임시저장·공개 수정은 **아직 아님.** 공개 수정이 확인될 때만 갱신일과 측정 시작일을 기록한다.
