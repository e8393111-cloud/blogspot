# 수정 발행 후 탭 정리 — 사용자 지시

사용자 지시: 수정 발행한 글은 계속 열어놓지 말고 닫는다.

완료 순서: 기존 글 수정 → 발행 → 공개 본문에서 변경 확인 → 해당 편집·공개 확인 탭 닫기.

이미 발행 확인된 글을 탭 정리를 위해 다시 발행하지 않는다. 확인을 마친 통계·자료 탭은 정리하며 가능한 한 기존 작업 탭을 재사용한다.

미완성 신규 초안은 수정 완료 글과 구분한다. 초안은 임시저장 목록에서 제목과 저장 시각을 확인한 뒤 탭을 닫는다. 저장되지 않은 내용을 버리거나 중복 초안을 새 글로 발행하지 않는다.
