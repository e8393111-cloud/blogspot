# 네이버 소제목 형식 검수

사용자의 기존 구성·서식 보존 지시를 적용한다. 글자 크기와 굵기 확인만으로 '기존 형식 일치'라고 보고하지 않는다.

## 실제 발행글 기준
비교 글: https://blog.naver.com/witchbloom82/224405541715 (연천)
- 일반 질문형 소제목: 네이버 기본 인용구 4, quotation_underline (밑줄형).
- 3초 요약·전화·체크리스트·예산 제목: 네이버 기본 인용구 2, quotation_line (세로선형).
- 소제목은 19, 굵기 해제. 인용구의 모양·여백·정렬까지 대조한다.
- 본문 15, 핵심 강조 16·굵게·분홍 #f02c8c. 주의사항 하이라이트는 기존 글과 같은 #f4d400.
- 사진 카드의 패널 금지와 본문 네이버 인용구는 다른 항목이다. 사진 패널 금지를 이유로 본문 인용구를 없애지 않는다.

## 완료 확인
1. 대상 글의 현재 본문과 모든 소제목을 읽는다.
2. 기존 발행글의 실제 인용구 유형을 확인한다.
3. 일반 텍스트 소제목을 해당 네이버 인용구로 전환한다. 선택 후 인용구 삽입은 선택 문구를 지울 수 있으므로 원문을 즉시 입력한다.
4. 다음 소제목으로 넘어가기 전에 유형과 원문을 확인한다. 입력 직후 응답이 지연될 수 있어 연속 일괄 편집을 신뢰하지 않는다.
5. 소제목 누락·중복·빈 인용구 0, 19 크기·굵기 해제, 본문 강조와 이미지·장소·실제 링크 보존을 확인한다.
6. 화면을 직접 비교하고 임시저장 목록의 저장 시각을 확인한 뒤 작업 탭을 닫는다.

이 문서는 서식 검수 기준이며 특정 원고의 발행 완료 기록이 아니다.
