# 교통·시간표 검증 기준
개정: 2026-10-06. 적용: Claude 취재·집필, GPT/Work 편집·이미지·발행.

## 통과 조건
- 공식 페이지를 열었다는 사실과 현재 운행에 적용되는 값이라는 판단을 구분한다. 페이지 열람일만으로 최신 시간표라고 하지 않는다.
- 시간표마다 노선/운송사, 정확한 승·하차 정류장, 출발 방향, 기점 출발인지 경유지 통과인지, 적용 시작일·종료일, 평일/주말/공휴일·축제 기간 조건, 출처 URL, 실제 열람일을 FACTS에 기록한다. 미표기 항목은 미확인으로 남긴다.
- 현재 운송사·터미널·교통정보시스템·예매 조회·운행 변경 공지를 우선 확인한다. 관광/축제 소개 페이지의 정적 표만으로 운행을 확정하지 않는다. 예매 조회에 안 나온다는 이유만으로 운행 없음이라 단정하지 않는다.
- 독자 제보를 포함해 다른 값이 발견되면 동일 노선·정류장·방향·적용일인지 먼저 비교한다. 출처 수가 많거나 공식 도메인이라는 이유만으로 한쪽을 채택하지 않는다. 제보 사진 역시 적용 조건 확인 전에는 정답으로 단정하지 않는다.
- 왕복 및 환승 구간을 각각 검증한다. 출발편만 확인하고 귀가 가능·막차·반나절 코스를 확정하지 않는다. 기점 시각에서 경유지 시각을 임의 계산하지 않는다.

## 충돌·미확인 처리
- 현재 적용 여부를 입증할 수 없거나 충돌이 해소되지 않은 정확한 시각은 본문·3초요약·표·이미지·캡션에 넣지 않는다. 근거 없는 범위·예상 시각으로 대체하지 않는다.
- '변경될 수 있음/방문 전 확인' 한 줄을 붙여 미검증 시간표를 발행하는 것은 금지한다.
- 핵심 교통과 귀가 동선이 불명확하면 '버스 시간 맞춘 코스' 등 제목의 약속도 통과하지 못한다. 공개 발행을 보류하고 임시저장·미해결 근거를 기록한다. 시간표를 빼도 글의 목적이 성립하는 경우에만 제목과 본문을 함께 재검수한다.
- 온라인 공식 자료·운행 공지·조회로 확인할 수 있는 범위까지 조사한다. 사용자에게 전화 문의를 의무로 떠넘기지 않는다. 이번 사용자 요청상 전화 확인을 전제로 해결 계획을 세우지 않는다.
- 실제로 후속 확인을 진행하지 않으면 '확인 중/곧 수정/확인 후 알려드림'이라고 쓰지 않는다. 확인된 사실, 확인하지 못한 범위, 이미 취한 조치만 말한다.

## 발행 전·후
- FACTS의 최종 검증값과 제목·본문·요약·시간표 이미지·캡션을 함께 대조한다. 원고만 고치고 구버전 카드 숫자를 남기지 않는다.
- 기존 글에서 충돌을 발견하면 영향 범위를 기록하고 사용자 요청에 따라 정정/비공개를 수행한다. Git 규칙 자체를 모든 글 비공개 전환 권한으로 해석하지 않는다.
- 실제 화면에서 저장/공개/비공개를 확인한 뒤 STATUS와 PUBLISHED-REGISTRY를 동기화한다. 비공개 글은 공개 내부링크 및 재발행 후보에서 제외한다.
- 재공개는 충돌 해소 근거·전체 숫자 QA·사용자 허용 범위가 갖춰졌을 때만 한다. 이 규칙 추가만으로 기존 글을 일괄 검수했다고 보고하지 않는다.
