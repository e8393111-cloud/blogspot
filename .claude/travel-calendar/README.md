# 월별 여행 캘린더 — 언제 어디를 쓸지 미리 정해두는 표

> **왜 만들었나.** 주제를 그때그때 고르면 시즌을 놓친다.
> CLAUDE.md에 *"발행 후 색인·랭킹에 2~4주가 걸린다. 10월 단풍을 노리려면 9월 중순 발행"*이라고 적어놨지만,
> 그 역산을 하려면 **어느 달에 어디가 뜨는지 미리 정리된 표**가 있어야 한다. 이 파일이 그 표다.

## 파일

```
calendar.tsv        본체 — 한 행 = 지역 × 시즌
measured-base.tsv   실측 원자료 (지역 · 월검색량 · 문서수 · 경쟁률)
sources.md          어느 값이 어디서 왔는지 · 등급
README.md           이 파일
```

원본은 이 저장소다. 스프레드시트 `1ErBrFXXGILQji_gH1K1bv_A7OUQ00jh0no8gU2IIaPE`의
`월별캘린더` 탭은 **폰에서 보기용 복사본**이며, 고칠 때는 여기를 먼저 고친다.

## calendar.tsv 컬럼

| 컬럼 | 뜻 |
|---|---|
| `발행권장` | ★**이 표를 쓰는 이유.** 시즌시작 −3~4주. 색인 지연을 역산한 값 |
| `시즌시작` `시즌종료` | `MM-DD`. **매년 반복되는 대략의 시기**(특정 연도 일정 아님) |
| `시즌사유` | 단풍 / 벚꽃 / 꽃축제 / 억새 / 해변·물놀이 / 눈·겨울 / 실내·박물관 / 축제(기타) / 상시 |
| `지역` | 주키워드의 앞부분 |
| `주키워드` | 현재 행은 과거 가볼만한곳 후보. 최종 제목은 실제 유입·검색 질문·본문 적합성으로 결정 |
| `월검색량` `경쟁률` | 실측값. 경쟁률 = 문서수 ÷ 월검색량. **후보 비교용 참고값이며 노출 가능성 보장은 아님** |
| `대표명소` | 그 시즌에 실제로 사람이 찾는 곳 |
| **`뚜벅이`** | ★`미조사` / `가능` / `조건부` / `불가` — **이 칼럼이 이 캘린더를 우리 것으로 만든다** |
| `상태` | `미발행` / `취재중` / `원고완성` / `검수중` / `임시저장` / `발행완료` / `보류` |
| `메모` | 헛걸음 함정, 재발행 사유 등 |

발행완료는 해당 시즌·질문의 실제 공개 글로 확인한다. 원고 커밋이나 같은 지역의 다른 글은 증거가 아니다. 과거 상태는 URL 대조 전까지 이력으로 보존하고 신규 자동 판정에 그대로 재사용하지 않는다.

## 큐 조건 — 자동 실행이 이 조건으로 주제를 고른다

```
상태 = 미발행
AND 발행권장이 오늘부터 3주 이내
AND 경쟁률 < 5
AND 뚜벅이 ≠ 불가
정렬: 발행권장 임박 순 → 월검색량 큰 순
```

재고가 3건 미만이면 그 실행은 **글을 쓰지 말고 캘린더 보충(키워드 실측)만** 하고 끝낸다.

## 갱신 방법

- **월검색량·경쟁률** — 월간 지표라 **월 1회면 충분**. `.claude/keyword-tool.md` 절차(Make 6031917 → 6032112).
- **뚜벅이** — 취재할 때마다 채운다. `미조사`로 남아 있어도 괜찮다. **모르면 모른다고 두는 게 맞다.**
- **시즌 날짜** — 해마다 조금씩 밀린다. 순(旬) 단위로만 적고 특정 날짜로 단정하지 않는다.

## ★쓰면서 지킬 것

- **경쟁률이 낮은 중소도시를 먼저 쓴다.** 실측상 `서울 가볼만한곳` 44.0 · `제주` 38.8 · `부산` 10.5로
  검색량은 커도 문서수가 압도적이라 후발 블로그가 못 뚫는다. `태백`·`단양` 1.1이 우리 자리다.
- **SNS에서 예쁜 곳 ≠ 검색되는 곳.** 인스타에서 좋아 보이던 영월 홍메밀꽃밭은 월 260이었고,
  덜 화려한 `태백 가볼만한곳`이 83,100이었다. **후보는 SNS에서 줍되, 줄 세우기는 실측으로 한다.**
- **날짜 의존 훅에 글 전체를 걸지 않는다.** 축제가 끝나면 글이 죽는다.
  1순위 훅은 상시 강점(65세 무료·역에서 도보 N분·실내)으로 잡고 시즌은 도입 한 줄로만 얹는다.
