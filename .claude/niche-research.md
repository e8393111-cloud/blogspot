# 니치 조사 — 40대 이상 국내여행 (2026-08-24)

블로그: blog.naver.com/witchbloom82 · **여행 카테고리 한정**(러닝 카테고리는 별도 운영)

## ★조사 방법과 한계 — 먼저 읽을 것
**이 조사는 웹사이트를 크롤링하지 않았다.** 이 환경은 프록시가 모든 외부 호스트의 CONNECT를
403으로 거부한다(`gateway answered 403 to CONNECT — policy denial`). 즉 **원문 페이지를 한 곳도 열지 못했다.**
사용한 것은 **WebSearch뿐**이고, 그건 제목·URL·요약 스니펫만 돌려준다.

그래서 아래 수치에는 **신뢰등급**을 붙였다.
- **A** = 법령·제도처럼 구조적으로 확실하거나, 서로 다른 질의에서 일관되게 반복된 것
- **B** = 독립된 2건 이상의 검색 스니펫이 일치
- **C** = 검색 스니펫 1건에서만 나온 값 — **방향 참고용, 단정 금지**

★★**이 문서의 수치를 블로그 본문에 사실로 옮겨 쓰지 말 것.**
루트 CLAUDE.md의 세션검증 규칙(출처 페이지를 실제로 연 값만 단정)을 충족하지 못한다.
**이 문서는 주제·니치를 고르기 위한 내부 의사결정 자료지, 발행용 팩트가 아니다.**

★**방향은 신뢰할 만하다.** 여러 갈래 근거가 전부 같은 쪽을 가리킨다 —
"부산·서울·경주 > 태백·서천", "5060은 걷기·휴식", "65세 무료는 서울에 몰려 있다".
**흔들리는 건 소수점이지 방향이 아니다.**

## 왜 조사했나
여행 글 20여 편을 130점까지 올려 발행했는데 일 방문 100~130에서 정체하고,
유입 검색어 상위 10개에 여행 글이 1건(1.54%)뿐이었다(→ `.claude/keyword-log.md`).
품질이 아니라 **과녁**이 문제라는 판단 아래, 40대 이상 국내여행 시장을 자료로 다시 봤다.

## 2. 5060이 실제로 가는 곳

**국내: 부산 > 제주 > 서울 > 독도 > 경주** / 해외: 오사카 — **등급 B**
(시니어 비서서비스 '똑비' 2024년 실요청 21,212건 분석. **서로 다른 2개 질의에서 동일하게 반복돼** 신뢰도가 상대적으로 높다)

→ **이 블로그엔 부산 글이 없다.** 대신 태백·서천·아산을 썼다. 이게 유입 부진의 직접 원인.
→ 오사카는 이미 1편 있음(해외 확장 시 재활용 가능).

## 3. ★행동 특성 — 우리 글과 어긋나는 지점

| 항목 | 값 | 등급 |
|---|---|---|
| **"완전한 휴식"이 여행 목적** | 40대 57.2% / 50대 63.6% | **C** |
| 비용 절감법 — 근거리 여행지 선택 | 36.5% | **C** |
| 비용 절감법 — 해외 대신 국내 | 36.1% | **C** |
| 여름휴가 비용이 부담된다 | 45.7% | **C** |
| 여름휴가 계획 있음 | 71.8% (전년 +2.7%p) | **C** |

> 개별 %는 C등급이지만, **"연령이 높을수록 휴식 지향"**이라는 방향은 여러 기사가 공통으로 말한다.
> 그리고 이 방향은 **우리 원고의 16시간 강행군 구조와 정면으로 어긋난다** — 그것만으로 충분히 행동할 근거가 된다.

### ★발견한 미스매치
독자의 **63.6%가 "쉬러"** 가는데, 우리 글은 이렇게 설계돼 있었다.
```
06:00 첫차 → 09:00 도착 → 동굴 → 점심 → 박물관 → 저녁 → 22:40 막차 (16시간)
```
**정보는 정확했지만 원하는 형태가 아니었다.** "다 보고 오는 법"을 썼는데 독자는 "쉬다 오는 법"을 찾는다.

## 4. `65세 무료` — 검증 완료, 생각보다 크다

법령상 **고궁·능원·국공립 박물관·공원·미술관 입장료 100% 면제**(65세 이상 내국인, 신분증 제시) — **등급 A**
(제도 자체는 법령 근거가 명확하고 복수 출처가 일치. 단 **개별 시설의 적용 여부·예외는 글 쓸 때 매번 재확인**한다.)
- 5대 궁(경복궁·창덕궁·창경궁·덕수궁·종묘) — 단 **창덕궁 후원은 경로도 5,000원 유료**
- 조선왕릉 전체(동구릉·서오릉·태릉·정릉 등) — 일부는 지자체 운영이라 개별 확인 필요
- 국립현대미술관 전관(서울·과천·덕수궁·청주) 전시 무료

★**전부 서울·수도권에 있고, 전부 지하철로 간다.** 이 블로그 조건과 정확히 맞는다.
★경쟁 글은 "무료 목록 나열"에 그친다. **가는 법·마감 시각·걷는 거리·화장실·벤치가 붙은 글은 없다.**

## 5. 결론 — 니치 재정의

> ### "5060이 대중교통으로 가서 **쉬다 오는** 곳"

| | 이전 | 이후 |
|---|---|---|
| **지역** | 태백·서천·아산 (경쟁 낮음 = 수요 없음) | **서울·부산·경주** (5060 실제 방문 1~5위) |
| **코스** | 첫차~막차 16시간 강행군 | **반나절·여유 코스.** "다 안 봐도 된다"를 명시 |
| **각도** | 정보 총정리 | **걷기 + 65세 무료 + 쉬는 자리**(벤치·그늘·카페·실내) |

### 우선 3편
1. **서울 고궁·왕릉 65세 무료 코스** — 지하철 도보권 + 무료 + 걷기가 한 번에 맞는 유일한 소재. 취재 부담도 가장 적다
2. **부산 뚜벅이 당일치기** — 5060 1위 여행지인데 블로그에 없다. 지하철·버스로 거의 다 돌 수 있어 뚜벅이 각도가 가장 잘 먹힌다
3. **서울둘레길·근교 걷기길 1구간** — 60대 시장 1위. 등산 블로그는 많아도 "대중교통 접근 + 화장실 + 벤치 + 경사"를 쓴 곳은 없다

## 조사의 한계 (정직하게)
1. **크롤링을 못 했다.** 프록시가 전 호스트 CONNECT를 403으로 막아 원문 페이지를 한 곳도 열지 못했다.
   전부 검색 스니펫 기반이고, 그래서 대부분의 수치가 C등급이다.
2. **정확한 월 검색량을 모른다.** 네이버 키워드도구·블랙키위에 접근할 수 없다.
   → 운영자가 후보 키워드의 검색량을 확인해 `.claude/keyword-log.md`에 적어 주면 이후 판단이 정확해진다.
3. **연간 집계라 계절·월 단위 수요를 설명하지 못한다.**
4. **'똑비' 데이터는 특정 서비스 이용자 표본**이라 전체 5060을 대표한다고 단정할 수 없다.

### 그럼에도 행동할 수 있는 이유
- 태백·서천보다 부산·서울·경주의 수요가 크다는 건 **어떤 표본으로도 뒤집히지 않는다.**
- 우리 원고가 16시간 강행군인 것은 **우리 문서를 직접 보고 확인한 사실**이다(외부 자료가 아니다).
- 65세 무료 제도는 **법령 근거**라 등급 A다.
→ **불확실한 건 정도이지 방향이 아니므로, 방향대로 3편을 써서 실측으로 검증한다.**
