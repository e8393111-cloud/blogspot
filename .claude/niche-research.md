## 이번 조사는 실측이다
네이버 **검색광고 키워드도구**(월간 검색량) + **검색 OpenAPI**(블로그 문서수)로 **키워드 155개를 직접 측정**했다.
앞선 조사는 검색 스니펫 추정이었고, **그 결과 여러 개가 이번에 뒤집혔다.** 아래는 실측값이다.

- `월검색량` = PC + 모바일 (검색광고 기준). `< 10`은 **10**으로 표기
- `경쟁률` = 블로그 문서수 ÷ 월검색량 → **낮을수록 좋다**

## 4. ★뒤집힌 가설 3개 (정직하게)

### ① "65세 무료가 제목 자산이다" → **틀렸다**
| 키워드 | 월검색량 |
|---|---:|
| 시니어 여행지 | 90 |
| 경로우대 할인 | 45 |
| 고궁 무료입장 | 25 |
| 65세 무료 관광지 / 65세 이상 무료 / 경로우대 무료입장 / 조선왕릉 입장료 / 경복궁 경로 무료 | **각 10 이하** |

→ **제목·주제로 삼을 수요가 없다.** 허브글 `65세 무료 관광지 모음`을 1순위로 밀었던 판단을 **철회한다.**
→ 단 **본문 안의 차별점으로는 계속 유효**하다(독자 신뢰·AI 브리핑 인용). **제목에 걸지 않을 뿐이다.**

### ② "저수요 지역을 골랐다(태백·서천·아산)" → **틀렸다**
태백 가볼만한곳 83,100 · 경쟁률 1.1은 **측정한 155개 중 최고 조건**이다.
지역 선택은 오히려 좋았다. **접미사가 전부를 망쳤다.**
→ "큰 지역 롱테일로 가라"는 권고도 **부분적으로만 맞다** — 부산·서울은 경쟁률이 10~44라 오히려 불리하다.

### ③ "걷기가 유망 니치다" → **대부분 틀렸다**
| 키워드 | 월검색량 | 경쟁률 |
|---|---:|---:|
| 서울둘레길 | 7,510 | 63.1 |
| 북한산 둘레길 | 4,660 | 31.1 |
| 남산 둘레길 | 1,960 | 41.4 |
| 노인 걷기 좋은 곳 / 평지 산책로 / 둘레길 대중교통 / 가을 산책코스 | **각 10** | — |

→ 시장 통계(60대 걷기 1위)는 맞아도 **검색 행동으로 이어지지 않는다.** 고유명(서울둘레길·북한산둘레길)만 살아 있다.

## 6. 할 일 (우선순위)

1. **★기존 20편 제목을 `○○ 가볼만한곳`으로 교체** — 새 글보다 싸고 효과가 크다.
   1순위: 태백·단양·제천·태안·서천 (경쟁률 1.1~2.3)
2. **신규는 황금구간 미발행 지역** — 여수(1.9) · 통영(1.9) · 속초(2.2) · 안동(3.0) · 가평(3.2)
3. **부산·서울·제주는 후순위** — 검색량은 크나 경쟁률 10~44
4. `65세 무료`·`걷기`는 **본문 차별점으로만** 유지, 제목·주제에서 내림

## 한계
- 검색광고 API는 소량 키워드를 `< 10`으로 뭉뚱그린다 → 표의 `10`은 "10 미만"이라는 뜻이다
- 경쟁률의 분모는 **블로그 문서수**라 실제 상위노출 난이도와 완전히 같지는 않다
- 측정 시점 2026-08-24. 월간 검색량이라 단기 변동은 작지만 **계절 키워드(단풍)는 시점을 탄다**
