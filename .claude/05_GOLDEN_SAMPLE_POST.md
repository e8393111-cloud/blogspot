## 복제할 실제 속성과 표시 예
| 요소 | 공개글에서 확인한 예와 속성 | 새 글에 복제할 요소 |
|---|---|---|
| 일반 본문 | “차 없이 KTX와 버스만으로 강릉 바다 당일치기, 됩니다.” / span 15px, weight 400 | 일반 본문 15, 굵게 해제 |
| 큰 소제목 | “🏖 강릉 바다, 어디서 뭘 하면 좋을까요?” / se-l-quotation_underline, span 19px, weight 400 | 인용구4·19·굵게 해제·번호 없음·주제 이모지 |
| 다른 소제목 예 | “🚄 KTX와 버스로 바다까지 어떻게 가나요?”, “📍 한줄 정리” | 같은 underline 구조 유지 |
| 일반 강조 | “경포 바다 산책 → 안목 커피 → 강릉중앙시장” / b 16px, weight 700 | 핵심 구절만 16·굵게 |

위 px는 공개 페이지에서 관측한 CSS 값이다. 사용자 규격의 pt를 CSS pt로 환산해 글자를 확대하지 않는다. 실제 편집기 저장값을 읽었다고 주장하지 않는다. span 아래 b의 굵기까지 확인하며, Markdown 표시만 붙여넣고 네이버 서식 적용 완료로 간주하지 않는다.

## 요약 인용구 — 관측과 적용의 차이
- 실제 제목: “📌 3초 요약·확인”.
- 실제 공개 컴포넌트: **se-l-quotation_postit**. 제목 19px·weight 400이며 요약의 일부 강조도 19px다.
- 이 글의 요약을 인용구2/quotation_line이라고 기록하지 않는다.
- 새 글은 사용자가 명시한 **01의 인용구2·quotation_line**을 적용한다. 샘플 선택을 인용구 규격 변경 승인으로 확대 해석하지 않는다.
- 보조 소제목 quotation_line의 실제 사례는 이 글에서 확인되지 않았다. 적용은 01의 보조 소제목 규칙을 따른다.

## 링크 배치 예
관련 설명 뒤에 짧은 안내 문구와 네이버 링크 미리보기 컴포넌트(se-oglink, se-l-image)가 이어진다.
- 관광 안내: “🔗 강릉시 관광 안내” → “비짓강릉” 카드 → https://www.gn.go.kr/tour/index.do
- 교통 안내: “🔗 강릉버스정보(강릉BIS)” → 링크 카드 → https://bis.gn.go.kr
- 철도 안내: “🔗 코레일 예매·시간표” → 링크 카드 → https://www.letskorail.com

복제할 것은 관련 문단 근처의 정상 네이티브 링크 카드 배치다. 카드 위 안내 문구 자체를 클릭 가능한 텍스트 링크라고 단정하지 않는다. 카드가 실패하면 01대로 클릭 가능한 일반 텍스트 링크로 전환한다. 위 주소는 공개글의 링크 속성 확인이며 외부 사이트의 최신 서비스 상태를 재검증한 기록은 아니다.

## CTA 위치와 실제 문구
“📍 한줄 정리” 본문 → 구분선 → **마지막 CTA 이미지** 순서를 화면에서 확인했다.
이미지 안의 두 줄 문구:

CTA는 작성자 본문의 맨 마지막이며 아래에는 네이버 광고와 플랫폼 태그 등이 이어진다. 복제할 것은 마지막 위치와 문구다. 이미지 제작 여부·실제 원본·라이선스·비율은 02를 따른다. 이미지 속 문구를 별도 본문 텍스트 노드로 관측했다고 기록하지 않는다.
