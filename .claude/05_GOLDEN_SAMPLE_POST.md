# 05 — 실제 네이버 렌더 기준 예시
확인일: 2026-09-29 KST. 역할: **실제 기준 예시는 무엇인가**. 아래는 공개 페이지를 브라우저로 읽고 DOM 및 화면으로 확인한 기록이다. 글 전체를 무조건 복제하는 템플릿이 아니라 **확인된 정상 요소만 복제하는 부분 골든샘플**이다. 규격은 01/02가 우선한다.

## 골든샘플
- 제목: **담양 가볼만한곳, 65세는 왜 상품권을 못 받을까요**
- 실제 공개 URL: https://blog.naver.com/witchbloom82/224418322812
- 카테고리: 짧은여행.
- 공개 화면 표시일: 2026. 9. 21. 8:31. Git STATUS/레지스트리의 9월 20일 기록과 다르므로 같은 날짜라고 단정하지 않는다. 이번 작업은 기존 발행 기록 정정 범위가 아니다.
- 확인 방법: 공개 목록에서 제목/주소 확인 → 단일 공개글 열람 → 실제 텍스트 노드·인용구·링크·장소카드·본문 끝 읽기 → 화면 확인. 편집기 진입·수정·저장·발행 없음.
- 안동 후보는 공개 목록에서 제목과 주소 https://blog.naver.com/witchbloom82/224412052623 를 확인했지만 개별 서식 실측을 하지 않았으므로 골든샘플로 채택하지 않는다.
- **무주 덕유산 공개글은 사용자 형식 불일치 지적 대상이므로 샘플에서 제외한다.**

## 복제할 실제 속성과 표시 예
| 요소 | 실제 표시 예/속성 | 복제 범위 |
|---|---|---|
| 일반 본문 | “담양은 광주 생활권이라 광주에서 출발하는 게 가장 빠르고 저렴해요.” / 텍스트 span 15px, weight 400 | 편집기 15·굵게 해제 |
| 본문 글꼴 관측 | se-nanumgothic, arial, 나눔고딕 계열 fallback | 확인된 네이버 기본 설정 유지; 모든 장치의 동일 폰트 보장 아님 |
| 큰 소제목 | “🚌 담양, 차 없이 가려면 어디서 어떤 버스를 타나요?” | 인용구4·숫자 없음·이모지 |
| 큰 소제목 속성 | se-l-quotation_underline, span 19px, weight 400 / 7개 모두 확인 | 편집기 19·굵게 해제 |
| 3초요약 | “📌 3초요약” / se-l-quotation_line | 인용구2 구조 |
| 일반 강조 | “담양터미널에 도착하면 돌아가는 버스 시간을 먼저 봐두면 마음이 편해요.” / b, 16px, weight 700 | 핵심 문구만 16·굵게 |
| 분홍 강조 | “★귀경 막차는 방면별·날짜별로 달라요.” / color:#f02c8c, 자식 b 16px·700 | #F02C8C·16·굵게 |
| 문단 간격 | 짧은 문단 사이 빈 문단이 있고, 본문 샘플 span line-height 27px | 짧은 호흡·빈 줄. 27px을 새 강제 설정으로 만들지 않음 |

공개 DOM의 px는 편집기 숫자와 대응되는 관측값이다. 사용자 규격의 pt를 CSS pt로 변환해 확대하지 않는다. span 자체 weight가 400이어도 자식 b가 700인 강조가 있으므로 실제 글자를 감싼 노드까지 확인한다.
MD의 굵게나 인용문 표시만 붙여넣어 네이버 서식이 적용됐다고 간주하지 않는다.

## 실제 링크 배치
교통 문단 아래에 짧은 일반 클릭 링크가 있으며 href가 실제 존재한다.
- “고속버스 예매 페이지 열기” → https://www.kobus.co.kr/main.do
- “시외버스 예매 페이지 열기” → https://txbus.t-money.co.kr/main.do
죽녹원 설명 근처 “죽녹원 공식 안내 열기” → https://www.juknokwon.go.kr/
메타세쿼이아 설명 근처 “메타세쿼이아길 공식 안내 열기”도 실제 href 확인.
시외버스는 정상 se-oglink 컴포넌트가 함께 존재한다. 일반 클릭 링크만으로도 허용한다는 01의 fallback 기준을 복제하며 링크 중복까지 강제로 복제하지 않는다.
이번 확인은 **공개글 내 링크 속성과 배치** 확인이다. 연결된 외부 사이트의 최신 운영 상태를 모두 다시 확인한 것은 아니다.

## 실제 장소카드 배치
se-placesMap 네이티브 컴포넌트 3개를 확인했다.
- 담양공용버스터미널: 교통 설명·교통 이미지 뒤, 다음 죽녹원 소제목 전.
- 죽녹원: 죽녹원 설명 구간 뒤, 다음 메타세쿼이아 소제목 전.
- 메타세쿼이아가로수길: 메타세쿼이아 설명 구간 뒤, 다음 운영시간 소제목 전.

복제할 것은 관련 절 근처의 네이티브 장소카드 구조다. 새 글에서는 01대로 관련 본문 바로 아래 넣는다. 실제 카드의 표시 주소가 원고의 목적지와 일치하는지는 글마다 다시 확인한다. 이번에는 카드 목적지 상세를 클릭해 재검증하거나 주소 사실을 새로 조사하지 않았다. 카드의 href가 #여도 네이티브 지도 컴포넌트이므로 가짜 링크로 단정하지 않는다.

## CTA 위치
공개글 마지막 사진 출처 캡션 뒤에 실제 두 줄:
> 공감 💗 + 이웃추가
> 뚜벅이 당일치기 코스 꾸준히 올려요

이 CTA 이후 본문 텍스트는 없음을 확인했다. 마지막 CTA 위치와 두 줄 구조를 복제한다.

## 글 전체 순서 — 관측과 적용을 구분
**실제 담양:** 제목/게시 정보 → 장소 표시 → 대표사진 → 도입 → 인용구2 3초요약 제목 → 요약 본문 → 큰 소제목 7개와 본문/사진/링크/장소카드 → 체크·정리 → 이전 여행 권유문 → 해시태그 → 마지막 사진·출처 → CTA 두 줄.
**새 글에 적용할 01 기준:** 제목 → 도입 3~5줄 → 대표이미지 → 📌 3초요약 → 본문(관련 링크·장소·사진) → 정리·관련 내부링크 → 필요한 출처/해시태그 → 맨 마지막 CTA.
담양의 사진 선행 순서를 새 표준으로 복제하지 않는다. 담양에서는 요약 제목이 인용구2이고 요약 항목은 뒤의 일반 텍스트 컴포넌트였다. 새 글의 요약 형식은 01을 적용한다.

## 복제 금지 / 미확인
- 담양 과거 이미지 생성 실패 스타일, 글자 뒤 미백/패널, 과한 타이포 등은 이미지 골든샘플이 아니다. 이미지는 **02_TRAVELBLOG_IMAGE_SPEC.md + blog-image-project-instructions-v2.md**만 따른다.
- 현재 본문의 긴 문단, 반복 구분선, 내용·요금·시간·계절 표현을 서식 예시라는 이유로 새 글에 복사하지 않는다.
- 담양 공개글에서 함께볼 여행글용 내부링크는 확인되지 않았다. 실제 배치 예를 지어내지 않으며, 새 글은 01대로 확인된 관련 공개 URL만 CTA 근처에 추가한다.
- 요약 외 별도 보조 소제목 인용구2 사례, 편집기 저장값, 모바일 장치별 줄바꿈, 현재 검색허용 설정은 이번 읽기 전용 공개 확인으로 검증하지 않았다.
- 위 미확인은 “확인 완료”로 승격하지 않는다. 골든샘플의 일부 차이를 이유로 01의 고정 규격을 바꾸지 않는다.
