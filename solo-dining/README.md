# 혼밥 가능 식당 찾기 PWA

혼자 먹기 좋은 식당을 검색하고, 별점·메모·방문기록을 남기는 모바일 PWA.

## 기능
- 🔍 카카오 로컬 검색 API로 실제 식당 검색 (음식점 카테고리 `FD6` 한정)
- ⭐ 혼밥 친화도 별점(1~5점)과 메모 — 내 LocalStorage에 저장
- 🍱 음식 종류 필터 (한식/일식/중식/양식/분식 등)
- 📍 내 위치 근처 1.5km 거리순 검색
- 🗺 카카오 지도에 결과 마커 표시
- 📑 즐겨찾기 / 방문 기록
- 📱 PWA 설치, 오프라인 셸 캐시

## 카카오 키 설정
1. [카카오 개발자 콘솔](https://developers.kakao.com/)에서 앱 생성
2. **앱 키 → JavaScript 키** 복사
3. **플랫폼 → Web → 사이트 도메인**에 이 페이지가 배포된 도메인을 등록
   (예: `https://<username>.github.io`)
4. 앱을 처음 열면 키 입력 화면이 나옵니다. 붙여넣고 저장.

> 키는 브라우저 localStorage에만 저장되며 서버로 전송되지 않습니다.
> 정적 호스팅 특성상 키 자체는 노출되므로, 카카오 콘솔에서 도메인 제한을 꼭 설정하세요.

## 로컬 실행
```bash
cd ..
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080/solo-dining/ 열기
```

도메인을 `http://localhost:8080`으로 카카오 콘솔에 등록해야 로컬 테스트가 가능합니다.

## 데이터
- 모든 사용자 데이터(평점·메모·즐겨찾기·방문기록)는 **이 브라우저의 localStorage**에만 저장됩니다.
- 다른 기기와 동기화되지 않습니다. 설정 화면의 “전체 데이터 초기화”로 삭제할 수 있습니다.
