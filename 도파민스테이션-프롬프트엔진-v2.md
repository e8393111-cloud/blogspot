## A. 왜 골드 스탠다드가 강한가 — 5대 원리

| # | 원리 | 작동 메커니즘 |
|---|------|---------------|
| 1 | **카메라가 역동성을 만든다** | orbital arc + 하강 + push-in. 피사체는 발광/부유로 거의 정지 → AI가 정밀 물리(칼질·손가락·천 시뮬)를 안 해도 됨 → 어색함 원천 차단 |
| 2 | **시차 레이어 4단 명시** | far(역회전 bokeh) / mid(지면 텍스처) / near(날개 엣지) / closest(코어 발광) → 진짜 3D 공간감, AI가 평면적으로 뭉개지 않음 |
| 3 | **단일 히어로 마이크로 모션** | 복부가 "한 번" pulse. 반복·다체·군중 모션을 배제 → 모핑·플리커 회피, 시선 집중 |
| 4 | **시네마틱 밀도 + 구체 라이팅·색 + 오디오 디렉션** | "deep amber and garnet", "golden veins", "warm drones, soft piano" → 모델이 추측할 여지를 없앰 |
| 5 | **피사체 = 발광·반투명·보석질** | AI가 가장 잘 뽑는 질감(서브서피스 스캐터링·굴절·bokeh). 실패율 낮은 재질로 후킹 확보 |

## B. 업그레이드 프롬프트 공식 (재사용 템플릿)

골드 스탠다드를 일반화한 8블록 골격. 새 컨셉을 만들 때 이 순서·밀도를 그대로 채운다.

```
[1 피사체]   결정질/반투명/발광/부유하는 히어로 1개 + 내부 발광색 + 질감
             (part X, part jewel 식의 하이브리드로 비주얼 후킹 강화)
[2 카메라 안무] Slow orbital arc(넓고 부드러운 원) + 미세 하강 + 그다음 immersive push-in
             → 어디서 멈추는지(엔드포인트) 명시. 피사체는 거의 정지.
[3 시차 4단]  Layer 1 far: 큰 soft bokeh orbs — 카메라 반대 방향 회전
             Layer 2 mid: 지면/배경 텍스처 — 아래에서 흐름
             Layer 3 near: 피사체 엣지 — 각도 따라 빛 다르게 받음
             Layer 4 closest: 피사체 코어 — 가까워질수록 더 따뜻하게 발광
[4 히어로 모션] 단 하나의 마이크로 모션이 "한 번, 아주 느리게"(pulse/bloom/breath)
[5 라이팅·색]  구체적 광원 + 컬러 팔레트 + 굴절/코스틱/스펙큘러
[6 무드]      cinematic ambient + 슬로 + 프리미엄/명상적
[7 오디오 디렉션] warm drones / soft piano / resonance, 템포 = 카메라 호흡
[8 공통 접미사] vertical 9:16, no text, no watermark, no logo, no subtitles + avoid:
```

**공통 접미사(필수):** `vertical 9:16, no text, no watermark, no logo, no subtitles`

**한 줄 공식:**
`[발광·부유 히어로] → [orbital+하강+push-in 카메라] → [시차 far/mid/near/closest 4단] → [단일 히어로 마이크로 모션 1회] → [구체 라이팅·색] → [시네마틱 무드] → [오디오 디렉션] → [9:16·무텍스트·avoid]`

### "AI가 약한 것" 회피 규칙 (하드 룰)
- **금지:** 정밀한 손/손가락 동작, 칼·도구의 물리 절삭, 군중·다체 정렬, 글자·로고·UI, 빠른 다체 모션, 사실적 얼굴 클로즈업.
- **대체:** 역동성은 **전부 카메라**(orbit/push-in/하강)로 만든다. 피사체 모션은 **발광·부유·1회 pulse**로 한정.
- **재질 우선순위:** 결정질 > 반투명 보석 > 액체/젤 > 연기/입자. (서브서피스·굴절·bokeh를 AI가 잘 뽑음)
- **모션 수:** 한 클립에 히어로 마이크로 모션 1개만. 두 개 이상이면 모핑 위험.
